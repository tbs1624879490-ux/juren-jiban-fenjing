# 角色档案：宋婉词

> 分类：主要配角｜状态：**守城战牺牲 → 后期复生（大结局）**｜首次出场：S1 空袭段
> 定位：江东市的精神图腾；糖糖生母；白帝剑仙。

## 一、基础信息
- 身份：江东市市长；武道强者（武皇级法相、昆仑传承）。
- 女儿：糖糖。
- 签名色调：白金、清冷剑光。

## 二、外观
- 正装风衣、长发披散时是强者的洒脱；着市长装束时干练威严。
- 法相**白帝剑仙**：昆仑山遗迹中领悟的上古传承，攻伐无双，号称"**一剑霜寒十四州**"。

## 三、性格
- 干练、果决、心系全城；女强人外壳下是位柔软的母亲。
- 做事讲规矩，也敢于在危急关头牺牲自己。

## 四、能力
- 白帝剑仙法相：御剑攻伐、凝剑气相，战力达武皇级。
- 城市管理者的调度权（城防、协会、军方特招衔接）。

## 五、阶段变化
| 章节锚点 | 事件 |
|---|---|
| ch31–40（空袭） | 空袭中以白衣身影在万米高空作战，气血风环击落大量魔鹫；战后部署善后、伤亡统计，并安排徐琨入伍封闭训练 |
| 守城战（约第二季，北境/大荒入侵期） | 江东遭遇史无前例的异兽狂潮；为掩护全城百姓撤退，**燃烧生命换取约三秒武皇级之力**，化作白帝剑仙屹立城市上空，最终壮烈牺牲——江东因此未沦为"下一个天州市" |
| 身后 | 女儿糖糖被徐家收养；叶清漪一度以**无相功化身**为她（世人"以为宋婉词复活"）以稳局面、护糖糖 |
| 大结局 ch434–437 | 借大结局"复生"归位，"欢迎回家" |

## 六、关系
- 女儿糖糖（她赴死的最大牵挂）；后辈徐琨、叶清漪（继承其守护之志）。

## S1 档案补充（EP01–12｜ch1–65）

> S1 口径：剧本 EP01–EP12 ＝ 原著小说 ch1–65。双轨记录：小说事件标 ch，剧本独有事件标 EP。

### S1 双轨经历时间线
- 小说轨：ch36–37 白色行政衬衫金丝眼镜登场，因徐琨训她"工作再忙，也要照顾好女儿"回以"你在教我做事？"；ch38 会所独白"我和他的年龄差，有一倍""算了，再等二十年吧"，公布"所有的异兽，都是异族豢养的战争兵器"；ch52–55 亲自带飞700斤的徐琨赴通天塔；ch63 高考遇袭仍坚持考试不停。
- 剧本轨：EP7 空袭中御空杀兽（高空远景）；EP9 踏空而至"有空……我们聊聊防务？"；EP10–11 坐镇高考主席台，秦天坠塔后当众定性"乃遭潜入的羽人刺客袭击，不幸坠塔，壮烈牺牲"，一语保下徐琨。

### S1 代表台词（逐字）
- 小说原文：ch37「你在教我做事？」；ch38「算了，再等二十年吧。」
- 剧本台词：EP9「最年轻的武圣。我这座城市，藏得够深啊。」；EP11（定性词）「乃遭潜入的羽人刺客袭击，不幸坠塔，壮烈牺牲」

### S1 结束状态
- 小说轨：市长任上，武圣，对徐琨情愫已明（对己）未挑破。
- 剧本轨：徐琨的政治庇护人，防务合作线开启。

### S1 关系演变
- 与徐琨：官方靠山→暧昧向上（S1止于暧昧，自我克制）；EP7 女儿获救、EP11 政治庇护，信任与情愫同步加深。
- 与糖糖：母亲身份贯穿（ch36–37"照顾好女儿"训话）；危机中稳如磐石。
