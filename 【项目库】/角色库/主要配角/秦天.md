# 角色档案：秦天

> 分类：主要配角（S1 反派）｜状态：**高考战中被徐琨一拳穿胸、坠塔毙命**｜首次出场：S1 联考段
> 定位：京圈太子、傲慢的"对照组"，徐琨越级打脸的对象。

## 一、基础信息
- 身份：帝都秦家嫡系少爷，转学到江东的"空降生"。
- 目的：为稳拿状元，故意"降维"来江东刷名次、立威。
- 关系：同伙林若男、叶婉儿（抱团）；死对头徐琨。

## 二、外观
- 衣着考究、贵公子打扮；神情倨傲、眼神轻蔑；被簇拥出场。

## 三、性格
- 自负、狠毒、输不起；打不过强者就对其至亲下手。

## 四、阶段变化
| 章节 | 事件 |
|---|---|
| ch22 联考 | 率众高调登场，轻视全场；看到徐琨 9999 控分，脸色难看 |
| ch56–59 高考 | 见徐琨以武圣身份参加高考，带头质疑"作弊"；万层爬塔中与林若男、叶婉儿密谋，企图借高重力层围猎徐琨 |
| ch9999 层 | 百倍重力下只能跪撑，目睹罗峰被一拳轰飞；自尊粉碎 |
| ch63 | 眼看争不过徐琨，怨毒转向**背对他、毫无防备的徐芸芸**，暴起偷袭 |
| ch63（毙命） | 徐琨转身一拳——拳透胸口，秦天倒飞撞破塔壁，自通天塔千米高空坠落，当场砸死；宋婉词定性为"遭羽人袭击牺牲"，保全秦家颜面 |

## 五、关系
- 徐琨（杀身之仇的对象）；徐芸芸（偷袭目标）；林若男、叶婉儿（同盟）。

## S1 档案补充（EP01–12｜ch1–65）

> S1 口径：剧本 EP01–EP12 ＝ 原著小说 ch1–65。双轨记录：小说事件标 ch，剧本独有事件标 EP。

### S1 双轨经历时间线
- 小说轨：ch42 转校生登场（一米八三），联考第一；ch43 三亿→四亿收买被拒，放话"高考那天，我会让你知道，什么是绝望"；ch57–59 密谋九千层围猎、跪迎计划；ch62 落居次席后心态崩塌，偷袭划伤徐芸芸；ch63 被徐琨一拳毙命坠塔，监控恰逢失灵，官方后被定性为「遭羽人袭击牺牲」。
- 剧本轨：EP5 降维来江东夺状元，轻蔑徐琨；EP10 提议联手围猎，百倍重力下跪地；EP11 杀意转向徐芸芸，被徐琨一拳贯胸坠塔，市长定性为"抗敌牺牲"（对照其章节档案定性「遭羽人袭击牺牲」，措辞以各轨原文为准）。

### S1 代表台词（逐字）
- 小说原文：ch43「高考那天，我会让你知道，什么是绝望。」；ch62「若是不能成为状元，我拿什么跟大哥争。」
- 剧本台词：EP10（提议联手）「九层以上，我们联手，先解决他！」；EP11「那我就毁了你最在乎的人！」

### S1 结束状态
- 死亡（ch63／EP11 被徐琨一拳穿胸坠塔）；官方定性「英雄化」（小说轨「遭羽人袭击牺牲」／剧本轨"抗敌牺牲"），家族仇恨埋线。

### S1 关系演变
- 单线敌对——从收买、下战书到伤妹，每一步都在升级自己的死期。
- 与林若男、叶婉儿抱团（围猎同盟）；对「大哥」（幕后靠山）卑躬屈膝。
