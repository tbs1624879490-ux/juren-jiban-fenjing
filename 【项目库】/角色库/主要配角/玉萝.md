# 角色档案：玉萝

> 分类：主要配角（S1 潜伏反派/刺客）｜状态：**登顶伏击失败，被徐琨击杀**｜首次暗线：S1 高考
> 定位：羽族（光明羽族）女战士型刺客，S1 最终战对手。

## 一、基础信息
- 身份：羽族精英刺客；奉命潜入人族、潜伏于通天塔最高处。
- 任务：在徐琨登顶时发动偷袭、暗杀这位人族最强考生。
- 关系：同族/异族幕后主使；目标徐琨。

## 二、外观（羽族真身）
- **头发**：金色长发
- **眼睛**：蓝色眼瞳
- **战甲**：白金色主体，混搭紫色纹路，符合光明系高贵美学
- **羽翼**：背后三对金色羽翼（共六翼），展开时壮观而威严
- **额印**：额头有一道光明临行印记，作战时会发光
- **光明女神像**：战斗或变身时，其背后会浮现光明女神虚影法相

## 三、变身机制
- **伪装潜入**：以少女人形伪装潜入人族考场，外观可隐匿真身特征（金发蓝眼在人形态时可调整为普通外观）
- **变身流程**：背后金色羽翼急速展开并包裹全身 → 金光闪烁形成蛋形光茧 → 光茧破开，羽族真身降临
- **视觉特点**：不血腥、偏仙侠美学，强调光明神圣感与异族威严

## 四、性格
- 隐忍、残忍、果决；出手即死招，失败即欲自爆同归于尽。
- 作为光明羽族战士，有严格的任务信条与赴死决心。

## 五、阶段变化
| 章节 | 事件 |
|---|---|
| 高考潜伏 | 藏身通天塔第一万层穹顶，屏息隐匿杀意 |
| 第 119 集 | 徐琨登台瞬间，从穹顶俯冲——白色羽剑刺进其后颈，低语"去死吧，人族天才"，催动风元素欲绞碎颈椎 |
| 第 120—121 集 | 徐琨早有防备，反手捏碎其脚踝；她惊觉羽剑"拔不出、刺不进"，被抡飞砸地；想断腿逃走，被一脚踏住 |
| 第 126 集（毙命） | 她燃烧能量核心欲**自爆**，徐琨一拳砸落、生生震散自爆，玉萝毙命 |
| 身后 | 徐琨检视尸身，其手指上戴着古朴**空间戒指**（内藏白色活蛋、大荒北域图，戒指有禁制、神识被弹开）——成为下一季的关键钩子 |

## 六、关系
- 目标徐琨（伏击者）；异族主使；与秦天案同为宋婉词"羽人袭击"定性提供依据。

## S1 档案补充（EP01–12｜ch1–65）

> 定名说明：小说 ch1–65 正文未命名，『玉萝』为项目定名（见全书剧情梳理），剧本已采用。
> S1 口径：剧本 EP01–EP12 ＝ 原著小说 ch1–65。双轨记录：小说事件标 ch，剧本独有事件标 EP。

### S1 双轨经历时间线
- 小说轨：ch39 潜入江东，读名单"名单上的所有人，都要死！"；ch44 袭击徐芸芸被徐琨挡下；ch45 转投林若男门下；ch64 通天塔一万层偷袭徐琨后颈得手；ch65 被诈死的徐琨反杀（捏碎脚踝、一拳砸头），尸体剥皮见白色绒毛与未长成的翅根。遗物空间戒指（白色活蛋、丹药、身份牌、御风诀、大荒北域图）归徐琨。
- 剧本轨：EP12 通天塔万层隐形伏杀，羽剑刺入徐琨后颈；被反扣捏碎脚踝，自爆"为了吾皇——"被一拳震散；ED钉子披露戒指内藏"白色活蛋与大荒北域图"（S2核心钩子）。（剧本中 ch39/ch44/ch45 的潜入与转投线未采用，玉萝于 EP12 首次登场即季终伏杀。）

### S1 代表台词（逐字）
- 小说原文：ch39「名单上的所有人，都要死！」；ch64「没想到我会在这里等你吧？现在……知道异族的可怕了吗？去死吧！人族的天才！」
- 剧本台词：EP12「去死吧，人族天才！」；EP12「拔不出……刺不进……」；EP12（自爆）「为了吾皇——」

### S1 结束状态
- 死亡；尸体揭出羽人族真身（白羽、翼根），遗留带禁制空间戒指归徐琨。

### S1 关系演变
- 小说轨：ch45 曾转投林若男门下（剧本未采用）；与秦天案同为宋婉词"羽人袭击"定性提供依据。
- 与徐琨：S1 最终战对手，伏杀者与反杀者的关系。
