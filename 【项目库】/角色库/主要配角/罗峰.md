# 角色档案：罗峰

> 分类：主要配角（主角最重要的同袍/对手—战友）｜状态：活跃｜首次出场：S1 通天塔段（ch60）
> 定位：兵王归来，从"最强竞争者"变成"最服气的兄弟"。

## 一、基础信息
- 年龄：约 21 岁（比徐琨略长）。
- 背景：北方荒野军团退役"兵王"，曾猎杀领主级异兽；回江东参加高考/通天塔认证。
- 签名色调：庚金白/金色（庚金虎血脉）。

## 二、外观
- 迷彩背心、刀疤、寸头/利落短发，浑身战阵杀伐气；身形悍勇。
- 法相/异象：庚金白虎（虎影、庚金之气）。

## 三、性格
- 冷酷、自信、极度好战；但为人磊落、敬真本事。
- 起初轻视徐琨"死肌肉、外强中干"，被一拳破纪录后心服口服，转为惺惺相惜。

## 四、能力
- 一个学期从高级大宗师突破到**武圣（三百万战力）**，被市场/资本视为风向标；战斗经验极丰富，擅长军格搏杀。
- 名言（设定讲解担当）：武圣打破基因锁只是开始，真正蜕变在"内景外显"。

## 五、阶段变化
| 章节 | 事件 |
|---|---|
| ch52 前后 | 通天塔先打出 **150 万**（高级大宗师）引起欢呼，资本看涨 |
| ch60（章名《罗峰》） | 正式登场，锁定徐琨 |
| ch62 前后 | 通天塔播报罗峰**晋升武圣（300 万）**，风向逆转、资本因徐琨更变态而恐慌；他自认"同等境界力量非唯一"，全力出手却连徐琨衣角都碰不到，被一拳轰飞，彻底服气 |
| 北境—星空 | 与徐琨并肩，成为四状元/战友团核心；见到武皇级千里一击会面如死灰，更坚定抱团 |
| 结局 | 人族强者之一，ch436–437 团圆 |

## 六、关系
- 徐琨：一生之敌→过命兄弟；唐萱、白景庭、陈浩南、许无双等状元团成员。

## S1 档案补充（EP01–12｜ch1–65）

> S1 口径：剧本 EP01–EP12 ＝ 原著小说 ch1–65。双轨记录：小说事件标 ch，剧本独有事件标 EP。

### S1 双轨经历时间线
- 小说轨：ch50 背景揭示（大宗师120万kg）；ch51 通天塔150万，轻蔑徐琨"一看就是一天十针药打出来的死肌肉"；ch60 以300万第37位留名武圣，"有没有可能……我也是武圣"；ch62 被徐琨一拳破防后干脆认输、当场交友。
- 剧本轨：EP9 留名150万"高级大宗师"，纪录被徐琨当众秒破，轻蔑转战意；EP10 冷静判断"能打9999的人……不像是会怯战"，9999层全力进攻被"太慢了"化解；EP11 示警并验伤。

### S1 代表台词（逐字）
- 小说原文：ch51「一看就是一天十针药打出来的死肌肉」；ch62「我认输。」「交个朋友，我叫罗峰。」「我当第二，你没意见吧。」
- 剧本台词：EP10「徐琨，同等境界，力气不是唯一。我会让你知道，什么是实战！」；EP9「谁说我华夏无人……」；EP11「小心——！」

### S1 结束状态
- 小说轨：初阶武圣（第37位留名），服软结盟，随军线待命。
- 剧本轨：被彻底打服的同期强者对照组，仍在考场线。

### S1 关系演变
- 与徐琨：宿敌→自愿当老二的兄弟，S1男性角色中唯一"棋逢对手"；军人式骄狂、输得起认得快。
