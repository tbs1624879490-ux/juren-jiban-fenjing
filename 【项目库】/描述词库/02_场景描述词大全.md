# 00 江东市 · 环壁主视觉（全季定调）

- **格局**：横屏宽幅城市全景。前景是观察者所在的高处俯瞰位；中景为江东主城核心；远景被环形城墙包围，城墙之外是荒野。
- **布局**：中央密集的数百米超高层摩天楼群自画面中心向两侧递减；楼群间有空中轻轨弧线、低空无人车道；一道百米高暗灰合金环壁横贯画面中后部，墙外荒原与旧楼废墟延伸到天际。
- **材质颜色**：摩天楼为深蓝灰玻璃幕墙 + 银灰合金骨架；霓虹以品红、青蓝、冷紫、琥珀金为主；环壁是哑光深灰合金，表面蚀刻发光阵纹。
- **全息成像**：楼体表面铺满流动巨型全息广告（人像、花纹、中文光字），半透明光带在高空环绕；空中悬浮 AR 信息层。
- **光影**：黄昏转夜，地平线留橙红色余晖，天空上半部转为深青蓝，云层被霓虹染色；空气透视强，远景微雾。
- **镜头跟随**：作为空镜定调，可做极缓推近；角色入场时从其肩后越过，城市在前方铺展。

# A. 江东一中

## 01 江东一中 · 操场

- **格局**：开阔室外运动场，呈横向展开；前景跑道、中景足球场与看台、背景教学楼与城市天际线。
- **布局动线**：红色塑胶环形跑道围绕中央绿色草坪（一端有白色足球球门）；右侧阶梯看台带顶棚；跑道近景嵌入一组合金测力终端；左侧高杆体育场照明灯。
- **材质颜色**：跑道为颗粒感红橙色聚氨酯塑胶，白色分道线；草坪是鲜亮人工草皮；看台浅灰塑料座椅；教学楼白墙配橙色横向装饰条与大面积玻璃窗。
- **设备逐件**：
  - **嵌入式测力平台**：长方形黑色防滑合金台面，边缘与四角镶嵌冰蓝色灯带，嵌在跑道边缘的金属底座上。
  - **立式数据终端屏**：银灰金属立柱托起一块倾斜显示屏，屏上是深蓝底 UI，中央圆形仪表、波形与大号数字（0.00），冷蓝光。
  - **右侧大型成绩公示屏**：粗银灰边框，深蓝界面列满成绩表格、柱状图、鹰形徽章。
  - 高杆多头投光灯、看台顶棚、广播喇叭。
- **全息成像**：操场上方横跨一道巨大的半透明冰蓝色全息光带，带运动人形图标、电路纹理与数据环，悬浮于半空微微发光。
- **光影**：晴朗白日，天蓝云白，阳光自右侧洒下，跑道与草皮有高光反射，地面微湿反光。
- **镜头跟随**：角色沿跑道起跑时，镜头侧面平移跟随并略压低；上测力台时从足底蓝灯带摇到面部；公示屏数据弹出，镜头自屏幕摇向角色反应。

## 02 江东一中 · 主干道荣誉榜

- **格局**：校园中央林荫大道，纵深透视强；左侧荣誉榜大屏，右侧道路向远处教学楼延伸。
- **布局动线**：宽阔平整的步道中央向校门方向延伸，两侧行道树、修剪绿篱、花境与休闲长凳；空中一架白色六旋翼拍摄无人机；道旁立蓝色道旗。
- **材质颜色**：步道为浅灰 / 米色光洁铺装，嵌入细蓝导引光线；金属长凳（木质座面 + 银灰金属侧帮带蓝光）；绿植层次丰富。
- **设备逐件**：
  - **荣誉榜大屏**：厚重银灰金属外壳包边，深蓝界面，顶部金色奖杯图标与「荣誉榜」字样，榜单列名次、姓名、分数（98.7、96.5…），右侧麦穗装饰。
  - **校训副屏**：竖屏蓝底，竖排白色「校训：明德、博学、笃行、致远」，底部城市剪影。
  - 白色社团无人机（云台相机、蓝色指示灯）、道旗、嵌入式地灯。
- **全息成像**：屏幕内容高亮、半悬浮感；远景楼宇间有玻璃空中连廊。
- **光影**：上午阳光透过行道树洒下斑驳光斑，地面湿润有反射，天空晴朗。
- **镜头跟随**：角色沿路走来，镜头自荣誉榜一侧横移带出，随后在其身后退跟；无人机入画时镜头跟随无人机升空再俯落回角色。

# B. 徐家老房子

## 03 徐家老房子 · 客厅

- **格局**：老式单元房一厅，长方形空间，层高偏矮（约 2.6m），墙面有岁月痕迹；右侧门洞通向厨房。
- **布局动线**：进门左侧一张格子布面木扶手沙发（靠外墙窗）；中央偏前一张深色实木大方餐桌配木椅；右侧靠墙一排深木电视柜；窗在远端外墙，门右侧通向厨房。
- **材质颜色**：地面深棕旧水泥 / 地砖，磨得反光；墙面米灰剥落、露旧痕；木家具为深红棕旧实木，漆面磨损；整体暖暗色调。
- **家具家电逐件**：
  - **壁挂大屏电视 / 全息屏**：薄屏挂在右墙，正播放紫蓝色调的城市夜景全息新闻画面（东方明珠式高塔、江景、数据框），屏幕边缘冰蓝光。
  - **实木电视柜**：深红棕色，多层抽屉与开放格，摆黑色长条音响、一台**圆柱形智能音箱**（黑色网罩、顶部和底部一圈蓝色光环）、小金属杯、相框、绿植。
  - 餐桌：磨损漆面，桌上陶碗（装橙子）、白瓷花卉茶壶、两个搪瓷 / 陶瓷杯、不锈钢保温壶、餐垫。
  - 格子布艺沙发（米色底红绿格纹、靠米色印花抱枕、搭一条旧毯子）。
  - 窗下铸铁暖气片；高背木制餐边柜（摆书、杂物、盆栽）；左侧壁挂旧空调（泛黄）；门洞旁墙挂**充电桩面板**（黑银、蓝色光环，充电枪垂挂）。
  - 厨房（门洞内可见）：浅色瓷砖墙、旧银灰冰箱、灶台锅具、吊柜与暖色灯。
  - 圆形挂钟、墙面旧照片 / 年历、小台灯、落地电风扇、墙角矮凳。
- **全息成像**：电视屏内容是立体城市夜景，蓝光映在抛光地面；屏幕 UI 带半透明数据面板。
- **光影**：夜晚，头顶一盏黄铜色工业风吊灯（外露灯泡、暖黄光）为主动光，电视与设备的冷蓝光作补，冷暖对撞；窗外透进紫蓝色城市霓虹。
- **镜头跟随**：角色自门口进入，镜头从其**肩后越过**扫过餐桌与全息电视，随其落座而降到餐桌高度；起身走向厨房时，镜头从侧后方低角度跟拍，门框自然形成前景。

## 04 徐家老房子 · 徐琨卧室

- **格局**：约 10㎡ 小卧室，长方形；右侧靠窗放床，左墙是书桌，中央偏左立测量仪。
- **布局动线**：进门沿书桌一侧可走到窗边；床靠右下墙角，床头小柜；测量仪立在房间中左部；墙上挂测力板。
- **材质颜色**：深棕实木地板，中央铺一块灰蓝几何方块厚绒地毯；墙面深灰蓝色；整体冷蓝夜调 + 桌面暖台灯。
- **家具家电逐件**：
  - **立式身体数据测量仪**：白色哑光机身，顶部弧形横梁嵌蓝色光源与摄像头，立柱嵌入竖排显示屏（屏上发光人体轮廓、数据波形），底部黑色方形踏板带两串发光脚印轮廓与冰蓝灯带。
  - **壁挂测力板**：黑色硬质合金长方形板，中央垂直导轨与圆形靶，四角固定，周围有孔洞与蓝色指示灯，安装在灰墙中央。
  - **书桌**：旧实木桌面，摆一台宽屏显示器（深蓝 UI、发光人体数据图）、键盘、金属笔筒、书本、耳机；黑色桌面工作台灯（暖光）。
  - 单人床：深色木床架带抽屉，灰蓝被褥，两个枕头，床尾搭深色毯子；床头柜上一盏小台灯（暖光）、小盆栽。
  - 多层壁挂书架（书、摆件、盆栽）、洞洞板（挂耳机、工具）、黑色办公椅。
- **全息成像**：显示器与测量屏上的人体轮廓、波形、数据呈半全息冷蓝成像；踏板脚印光带。
- **光影**：夜晚，窗外城市霓虹与星空，室内冷蓝仪器光为主，台灯暖光点缀，地面反射设备光。
- **镜头跟随**：角色上床时镜头自测量仪一侧随其步伐横移；晨起站上测量仪，镜头从踏板脚印光缓缓上摇到屏幕再到面部；对镜出拳时快速贴近测力板，随冲击一震。

# C. 民政局

## 05 民政局 · 政务大厅

- **格局**：挑高明亮的现代政务大厅，开阔通透；左侧自助拍照舱，中央一排智能采集台，远景办公窗口。
- **布局动线**：入口正对一排白色服务岛台；居民从取号 → 生物采集 → 拍照 → 出证单线流动；地面光洁引导人流。
- **材质颜色**：白色大理石 / 高光环氧地面（强反射），白色圆柱与玻璃幕墙，点缀冰蓝色灯带与包边；整体冷白 + 科技蓝。
- **设备逐件**：
  - **自助证件拍照舱**：白色圆角舱体，一侧挂深蓝色遮光帘，舱内全息城市背景屏、一张圆形升降凳；外壁竖排显示屏（证件照占位头像、功能按钮）。
  - **生物信息采集台**：白色岛台式，台面立虹膜 / 人脸摄像头（黑色球形云台、蓝色光环）、指纹 / 掌纹模块、竖屏显示器（发光人脸线框）。
  - 背景整面巨型 LED 宣传屏（国徽 / 城市形象、功能图标矩阵）。
  - 叫号屏、白色花盆绿植、悬空灯带。
- **全息成像**：屏幕上人脸线框、证件照、功能图标均为冰蓝全息风；宣传屏画面通透立体。
- **光影**：白日，自然光自玻璃幕墙洒入，天花线性灯补光，地面反射明亮。
- **镜头跟随**：角色被引导进拍照舱，镜头在舱口外侧随帘幕轻晃；录虹膜时给眼部与屏幕交替特写；红本打印时镜头随出证口下移，再跟到两人手中。

# D. 北辰武馆

> 名称口径：正名「北辰武馆」。场景卡门头图中字样曾生成为「天启武馆」，统一按正名描述。

## 06 北辰武馆 · 大门大厅

- **格局**：极高挑空（约 4–5 层通高）的硬朗金属大厅，对称纵深；入口闸机，中庭悬浮环形导览屏。
- **布局动线**：前景一排银色翼闸与人脸闸机；入内左右两侧立仿山石景与造型松，中庭地面有圆形仪式台；纵深尽头是接待背景墙与 logo；两侧回廊、墙面挂武术人形竖幅。
- **材质颜色**：地面深色高光大理石，嵌冰蓝地光；结构为哑光黑钢 + 拉丝银钛金属；天花环形灯带；冷峻深色 + 冰蓝光。
- **设备 / 陈设逐件**：
  - 多组银色速通翼闸（黑色刷卡面、蓝光）。
  - **中庭悬浮环形全息导览屏**：圆柱环形屏，蓝色界面，中央发光武术人形图标，四面分屏画面，悬空缓缓转动。
  - 门头横匾（深色金属底、银色立体馆名、中央菱形徽标，两侧蓝色灯带）。
  - 两侧落地竖幅（水墨武术人形）、天然岩石造景、盆景松、壁挂信息屏。
- **全息成像**：环形导览屏为半空全息成像，光纹通透；地面有环形光带。
- **光影**：白日，天光自高窗洒下形成光束，冷蓝主调，金属表面高光冷冽。
- **镜头跟随**：角色刷卡过闸，镜头自闸机外侧低角度随其穿过，随后在大厅中缓缓后退抬升，带出挑空中庭与悬浮环屏。

## 07 北辰武馆 · 综合测试区

- **格局**：高大的工业风训练测试厂房，横向铺开；左侧巨型测力架，中央跑道，右墙整面数据大屏。
- **布局动线**：沿力量测试区 → 跑道 → 器械区分区排列；地面嵌发光跑道线。
- **材质颜色**：抛光混凝 / 金属地面，暴露的钢梁与管道，拉丝金属器械；冷蓝灰主色，器械点缀黑色防滑橡胶与黄色警示条。
- **设备逐件**：
  - **重型立式测力架**：粗壮黑色钢架 + 花纹防滑金属踏板，黄黑警示边；上部挂大型圆形黑色拳靶（红圈靶心）；侧面斜置触控数据屏（深蓝 UI）。
  - **光栅跑道**：黑色耐磨地面，白色分道线，两侧立式光栅柱（蓝光），尽头计时门。
  - **右墙巨型数据屏**：深蓝界面分屏显示发光奔跑人体线框、跑道俯视图、心率 / 波形、柱状图。
  - 右前一台重型合金框架跑步机（多屏仪表）；背景哑铃架、综合器械。
- **全息成像**：大屏人体线框与数据为冷蓝全息投影，跑道光栅有立体光帘。
- **光影**：冷白 + 冰蓝顶灯，天花长条灯，地面反射屏幕冷光。
- **镜头跟随**：角色上测力架时镜头自踏板摇到拳靶；冲跑道时侧面跟跑，冲线瞬间随光栅光帘一闪而停。

## 08 北辰武馆 · 自助餐厅

- **格局**：五星级酒店级弧形自助餐厅，环形取餐台居中，纵深可见落地窗与城市景观。
- **布局动线**：沿弧形餐台顺时针取餐；后厨补给在餐台内侧；右侧悬挂式冷藏肉柜。
- **材质颜色**：亮面不锈钢餐台、白色大理石地面（纹理反射暖色光）、天花环形水晶吊灯；暖金主调 + 冰蓝冷柜光。
- **陈设设备逐件**：
  - 多层弧形保温餐台，不锈钢罩、铜金色保温吊灯（下射暖光）。
  - **能级标牌**：餐台上方悬挂四块竖向电子牌——红色「Lv.3」（异兽头像）、冰蓝「Lv.4」、金色「Lv.5」、紫色「Lv.6」，霓虹描边。
  - 白色碎冰展台（刺身 / 异兽海鲜）、悬挂式冷藏柜（吊挂肉类、蓝色冷光、电子温控屏）、堆叠白瓷盘。
  - 天花大型水晶吊灯 + 环形灯带、造型盆景松。
- **全息成像**：能级牌为发光全息标牌；冷柜玻璃有冷雾与蓝光。
- **光影**：傍晚，暖黄餐台光与冷蓝柜光交错，水晶灯璀璨。
- **镜头跟随**：角色端盘取餐，镜头从餐盘一侧低位平移跟随，经过能级牌时上摇带出牌面；落座后镜头随其动作在空盘与面部间切换。

## 09 北辰武馆 · 重力室

- **格局**：封闭八角形科技训练舱，中央圆形重力台，四周厚重金属墙体。
- **布局动线**：入口正对圆形升降训练台；左侧控制面板墙；空间封闭无窗。
- **材质颜色**：哑光钛合金墙板（拼缝、铆钉、几何加强筋），深色金属地面带黄色警示环；冷蓝主调。
- **设备逐件**：
  - **重力控制台**：壁挂斜屏，深蓝 UI，左侧人体示意图，右侧竖向档位「1.0G / 1.5G / 2.0G / 2.5G / 3.0G」高亮。

- **镜头跟随**：角色向上攀爬，镜头以大仰角随其绕中轴螺旋上升；跨入更高重力层时镜头随之一沉，呼吸感增强。

## 23 通天塔 · 第一万层塔顶

- **格局**：高空露天圆形石台，几根巨型古典石柱支撑环形顶盖，四周无墙、云海环绕。
- **布局动线**：石台中央刻同心圆法阵纹路，边缘无护栏、临云海；入口阶梯自下方接入。
- **材质颜色**：银灰大理石柱（描金纹、内嵌蓝光）、抛光石台（金色法阵刻线）；冷暖交融。
- **陈设逐件**：石台上数个青铜火盆（燃蓝色火焰）、环形石凳、刻纹地面。
- **全息成像**：中央法阵金色刻线微微发光，蓝色火焰能量点漂浮；云海中隐约浮现远处浮空城。
- **光影**：日出 / 日落金光从云海平面射来，长影铺地，云海翻涌透光。
- **镜头跟随**：角色踏上石台，镜头从阶梯侧后跟随绕到台缘，俯瞰云海时镜头越过其肩头；交战时绕石柱快速移动跟拍，蓝火在前景掠过。

# I. 荒野与防空

## 24 荒野区

- **格局**：俯瞰式末世荒原，前景废弃公路与锈蚀车辆，中景倒塌高架与残楼，远景巨兽剪影与残破天际线。
- **布局动线**：龟裂的旧公路向废墟深处延伸，沿路是翻覆车辆与倒塌标牌。
- **材质颜色**：枯黄荒草、锈红铁皮、灰暗混凝土；暖橙夕照 + 冷雾。
- **陈设逐件**：锈蚀报废轿车、断裂高架桥（混凝土裸筋）、扭曲路标、枯树、碎玻璃、石块水洼。
- **全息成像**：远景悬浮一座黑色棱形浮空建筑（蓝色光点）；雾中巨大异兽轮廓带微弱蓝光纹路。
- **光影**：黄昏逆光，尘雾弥漫，长投影，天地交界昏黄。
- **镜头跟随**：角色沿废公路前行，镜头低位侧后跟拍，前景荒草掠过；发现异兽时镜头随其视线急推远景，再切低角度。

## 25 环壁 · 防空阵地

- **格局**：环壁顶部的军事平台，弧形城墙延伸；前景重型激光炮，中景导弹垂直发射井，中央能量盾核心。
- **布局动线**：沿墙顶通道布置炮位、雷达、发射井；中央穹顶能量盾发生器。
- **材质颜色**：哑光军灰金属、混凝土、银钛炮管；冷蓝主调，远山积雪。
- **设备逐件**：
  - **重型激光防空炮**：多关节机械臂炮台，多束平行蓝色能量管线，炮口蓄能蓝光。
  - 垂直导弹发射井（白色导弹、黄黑警示）。
  - 碟形雷达天线、通讯塔、中央**半球能量盾发生器**（蓝色穹顶光罩、核心光球、环形电路光纹）。
  - 地面黄黑警示标线、设备箱。
- **全息成像**：能量盾穹顶为半透明蓝色网格光罩，地面阵纹电路全亮。
- **光影**：阴云冷光转天际线微亮，蓝能量光映在湿润金属表面。
- **镜头跟随**：角色登上阵地，镜头沿炮轨横移；预警时随其目光扫向天空，能量盾展开瞬间镜头快速拉升展现穹顶全貌。
