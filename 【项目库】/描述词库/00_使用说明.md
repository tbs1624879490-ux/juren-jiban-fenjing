# 【描述词库】使用说明

> 建立：2026-10-09｜触发：王导要求——根据已生成图片与参考图，把**全部角色、场景库、道具库**用高颗粒度描述词写出来，细到材质、颜色、家电、布局、全息立体成像，并写明镜头如何在场景中跟随角色。

## 一、定位

描述词库是"图片 ↔ 文字"的双向权威：
- 对**生成端**：可直接抽取为出图提示词（人物 / 场景 / 道具一致性）。
- 对**分镜端**：提供每个空间的格局、动线、光源、可跟随的机位路径。
- 所有描述均**对照已生成的图片逐张核对**，不凭空创作；剧情与既有角色卡 / 场景库一致。

## 二、颗粒度标准（每条必须覆盖）

| 类 | 必填维度 |
|---|---|
| 角色 | 体型比例 / 发型发色 / 五官肤质 / 服装结构 / 布料材质 / 配色 / 神态微表情 / 签名光效 / 镜头跟随 |
| 场景 | 空间格局 / 平面布局与动线 / 墙面地面天花材质 / 颜色基调 / 家具家电逐件 / 全息立体成像 / 光源方向 / 镜头跟随角色的路径 |
| 道具 | 整体造型 / 结构部件 / 金属·玻璃·塑料材质 / 颜色与发光 / 全息 UI 细节 / 握持或陈列方式 |

## 四、使用约定

- 写分镜 / 出图时，从对应条目整段复制，再按镜头需要裁剪。
- 图片若迭代重做，描述词同步更新并保留版本日期。
- 描述中出现的图片与设定不一致处（如门头字样），以世界观正名为准并在条目下标注。
