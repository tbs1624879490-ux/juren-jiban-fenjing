## 01 灵环（全民智能手环）

- **整体造型**：一枚闭合 / 微张的流线型镯环，有机曲面如液态金属凝固，无任何棱角；截面圆润贴合腕部。
- **结构部件**：环身外侧嵌一颗椭圆形凸起的蓝色能量核心（如宝石），周围分布微型传感器小孔与指示灯点；内侧为生物感应面。
- **材质颜色**：高抛光镀铬银金属，边缘过渡到深枪灰；反射环境光，镜面质感。
- **全息 UI**：核心上方投射半透明冰蓝色全息屏——时间（10:24）、心率 72bpm、电量 / 血氧 98%、心电波形；佩戴者前臂皮肤上另投射「AI Health Monitor · Real-time」细线框字样与六边形图标。光屏下缘有圆形加载光环。
- **握持陈列**：常态佩戴于手腕；产品图为浅灰白纯净背景，侧光突出镜面反射。

## 02 武者通讯手表

- **整体造型**：大尺寸粗犷军规腕表，圆形表盘，表壳多颗外露防撞螺丝，右侧大纹理表冠与功能按键。
- **结构部件**：厚实金属表圈（铭刻 N/E/S/W 方位刻度与箭头）、橡胶 / 复合材质宽厚表带（横向透气槽）。
- **材质颜色**：拉丝枪灰钛金属表壳 + 哑光黑表带，防滑纹理；硬朗军工质感。
- **全息 UI**：表盘深蓝底战术 HUD——卫星坐标（34.0522°N / 118.2437°W）、GPS 信号格、地形俯视图、中央蓝色方位箭头、红色目标锁定点；周边 ALT 482m、SPD 0.8m/s、DIST 3.6km；下方 HEALTH 98% 绿色进度条与 AMMO 30/120 数据块。
- **握持陈列**：佩戴于腕；广告场景置于粗糙湿润岩石上，背景虚化的冷峻山脊，冷光勾边。

## 03 护臂光脑

- **整体造型**：覆盖前臂的流线型护臂，前粗后细，符合人机工学；后端开口内衬黑色软垫与束带。
- **结构部件**：臂甲外侧一条长条形透明显示窗，前端一枚圆形主按键（带光环），侧面散热刻线与卡扣，后部可调节绑带。
- **材质颜色**：哑光银钛金属甲片 + 抛光边框，黑色织物绑带；金属表面细微拉丝。
- **全息 UI**：显示窗内冰蓝光的脑波 / 数据扫描图；护臂上方投射悬浮全息屏——旋转的线框大脑与「BRAIN ACTIVITY」面板，分列 COGNITIVE / MEMORY / FOCUS / EMOTION 数据条，顶部 SCANNING 字样，扫描光环转动。
- **握持陈列**：穿戴于前臂，平放展示于深色反光台面，浅景深。

## 04 黑金卡

- **整体造型**：标准金融卡尺寸，圆角矩形，卡面为黑色底 + 金色纹饰。
- **结构部件**：左侧一枚金色方形 EMV 芯片；卡面顶部六边形立体徽标，右侧盾牌纹章（盾内嵌字母 A 与皇冠）。
- **材质颜色**：哑光黑金属 / 高端 PVC 基底，表面压印细密的波浪形金纹（类似指纹 / 等高线），金粉质感。
- **图文细节**：凸起的金色字组「AURUM · BLACK EDITION」、卡号 8888 连号、CARDHOLDER NAME；右下角「VIP · INFINITE」。
- **陈列**：斜插于黑色绒面金属盒中，暖色聚光打在金边与芯片上，背景深色虚化。

## 05 家用身体数据测量仪

- **整体造型**：立式一体机，底部方形踏板 + 中央立柱 + 顶部圆角显示头，极简白色家电风。
- **结构部件**：踏板四角银灰色电极片；立柱中嵌竖向蓝光带，两侧银色握持电极把手（可伸缩）；顶部黑色显示屏。
- **材质颜色**：哑光白塑 / 金属机身，银灰电极，整体洁净。
- **全息 UI**：顶部屏黑底亮白数据——体重 52.6kg、BMI 20.4、体脂率 18.7%、人体小图标、Wi-Fi 标志；立柱蓝色光带与踏板前蓝光条呼应。
- **陈列**：置于明亮家居环境，浅色木地板，背景浅蓝抽象挂画、窗边绿植与城市远景。

## 06 黑陨铁山（测力装置）

- **整体造型**：一块竖立的巨型不规则陨铁巨石，上尖下宽、表面嶙峋，底部石质基座。
- **结构部件**：正面纵向嵌入一条科技导轨，中部圆环靶心（蓝色能量核心），下部第二个同心圆刻度盘；蓝色能量流自顶部沿导轨贯穿至底座。
- **材质颜色**：深黑近炭的陨铁岩石，粗糙嶙峋的天然石面，边缘带灰白石棱；裂缝中透出蓝 / 金色微光。
- **全息 UI**：靶心与刻度盘发出冰蓝光，能量光线沿刻纹流动，表面雷纹状蓝电流光。
- **陈列**：立于荒野石台之上，四周群山与云雾，阴沉天空，氛围威严；作为力量认证的图腾。

## 07 医疗修复舱

- **整体造型**：横置圆筒形舱体，左端圆形舱门光环，顶部铰接一条多关节机械臂。
- **结构部件**：高透弧形舱盖（可开合）、内部白色垫床与枕头；顶部白色机械臂末端是多功能治疗头（蓝光、精密器械）；舱体侧面嵌入式显示屏；底座带蓝光带。
- **材质颜色**：白色医疗级高光外壳 + 镀铬机械关节 + 透明强化玻璃舱盖，银色管线；洁净冷白。
- **全息 UI**：侧屏与壁挂监护屏（深蓝医学界面、人体轮廓、波形）；舱体标号「R-01」；机械臂治疗头下投蓝色光锥。
- **陈列**：在洁净实验室中，玻璃墙后隐约设备与「Advanced Medical Repair System」字样，冷调顶光。
- 备注：卡图舱内有匿名患者示意，实际使用时舱内可空。

## 08 空间戒指

- **整体造型**：一枚宽版古朴银戒，戒面较宽、厚度饱满，戒圈圆润。
- **结构部件**：戒面满布手工錾刻的玄奥纹路——卷曲云气、星辰圆点、旋涡纹，中央一枚圆点星芒。
- **材质颜色**：做旧纯银 / 陨铁银，凹陷处氧化发黑，凸起棱线磨光发亮，明暗对比强烈。
- **全息 / 异象**：纹路深处似有极淡幽光（对应内部空间禁制）；神识探入会被禁制弹开。
- **陈列**：斜置于粗糙深色岩石面上，侧逆光突出錾刻凹凸与银质反光，背景虚化暗调。

## 09 针剂与营养液

- **整体造型**：一组医用针剂与输液袋组合。
- **结构部件**：细长安瓿瓶（尖顶可掰口）、橡胶封口小药瓶、透明软质输液袋（带悬挂口、下接滴管与软管）；托盘为透明亚克力分层架。
- **材质颜色**：高透玻璃 / 塑料，银色金属封口；液体内含发光微粒，呈冰蓝色冷光。
- **全息 UI**：标签「NUTRITION INJECTION · 10ml」（十字标识）、输液袋「NUTRITION INFUSION · 500ml」，附 VITALITY SUPPORT / IMMUNE BOOST / CELL REPAIR 字样；冷藏屏显雪花图标与 2℃。
- **陈列**：置于冷藏柜内，冷白 + 冰蓝光，玻璃搁架反射整齐排列的瓶身。

## 10 外骨骼步兵装甲

- **整体造型**：约 2.5m 高的无人 / 可穿戴重型外骨骼，人形直立，肩宽背厚，军事压迫感强。
- **结构部件**：双肩厚重装甲护片（右肩印编号 03、白色三角徽记）、胸腹部战术背心模块（魔术贴面板、四个弹匣包、腰包）、外露液压杆与金属骨架、大腿 / 小腿装甲分片、重型机械足；左臂挂一把长管战术步枪。
- **材质颜色**：橄榄绿 / 卡其色装甲板 + 哑光黑液压与关节，金属银液压杆；战损做旧质感。
- **发光 / UI**：背景监控屏泛冷蓝光（人体线框），金属表面冷高光；无多余发光，强调实战厚重。
- **陈列**：立于暗色军械库，背景武器架与设备箱（印 MIL-STD EXO SUIT INFANTRY），顶光冷硬，地面反射。
