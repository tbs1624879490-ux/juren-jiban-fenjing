## 七、画面喜剧语法（赛博卡通 · 拉片蒸馏 2026-10-19）

> 不依赖台词的"画面层"喜剧与高燃语法，归涂鸦彩墨层（与风格升级件"欢快感引擎"配套）；视觉规格见美术库《游戏化赛博特效》，镜头见武戏库"卡通物理"。源公共库/番剧/开局地摊卖大力。

| 手法 | 怎么做 | 笑点/燃点 |
|---|---|---|
| 3D 拟声词砸屏 | 音效（砰/哐/咔/啵/轰）做成带 halftone 网点、撞色描边、撕裂边缘的立体字，颜色绑定攻击色；大绝招占满屏、小招局部 | 打击"看得见、听得响"，夸张解气 |
| 团状尘云 | 落地/受击/翻滚用 2D 团状白烟，不写实扬尘 | 摔得响、不疼，卡通化伤害 |
| 杂物飞溅 | 砖石/课桌/瓦片/物件沿冲击方向飞出 | 力度可视化 |
| 长翻滚/贴地滑行 | 受击拖长速度线、撞翻物件再起身 | 狼狈喜感、缓冲暴力 |
| 强透视冲镜头 | 拳/手/道具用广角画大直冲镜头 | 破壁拉客、猝不及防 |
| 表情符号化 | 怒=头顶喷漆"爆"字、无语=线稿蓝框定格、懵=??（沿用风格件/鱼太保） | 情绪一眼可读、省预算 |
| 多格漫画快切 | 收尾连续切多机位＋定格帅气 pose | 漫画分镜式的"帅气收尾" |
| 波普放射板 | 3D 角色身后插平面撞色放射板/色块 | 高燃/叫卖感，2D/3D 混用 |
| 闲手操作反差 | 大敌当前却慢慢翻牌/看面板/算计代价 | 从容感＝最强装逼 |
| 道具一物多用 | 同件道具一场变形三次（投掷武器→裹身缓冲团→披风/铺场布） | 道具会"演戏"，省预算又出记忆点 |
| 空中坠落喜感 | 离镜缩 Q 版质点＋多轴翻滚＋失重定格瞪眼＋手里饭盆不撒手 | 空中也有戏，危险越急表情越呆 |

**适用边界**：日常/校园/市井/系统技能/高燃反打可用；**战斗高光正拍（爆城/法相/认真击杀）转暗金泼墨/水墨，不卡通化**（风格件执行规范 4）；每集"涂鸦小剧场"插入帧控制在点到为止，不连续垄断。整场喜剧打斗按武戏库第六节"以一敌百波形"铺，空战喜剧拍按武戏库第五节。

## 使用提示

- 干饭 / 体型梗配快节奏与反应特写；母爱梗停顿留白、不演成搞笑。
- Running gag（母亲端饭、盘瑶缩水、竖中指、要孜然）固定动作与机位，形成招牌。
- 反派 / 岳父装逼给足铺垫再一秒破功。
- 画面喜剧（3D 拟声词/团状尘云/长翻滚/强透视）服务日常与高燃反打，战斗高光正拍不卡通化；系统操作反差（临阵翻牌/加点结算）是赛博系统线的招牌笑点。
