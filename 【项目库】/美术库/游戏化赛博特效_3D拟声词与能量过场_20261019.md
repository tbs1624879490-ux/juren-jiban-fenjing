## 一、3D 立体美漫拟声词规格（涂鸦彩墨层的"砸屏"升级）

### 1.1 与既有"书法字砸屏"的分工（不可混用）
| 类型 | 质感 | 用在 | 归属层 |
|---|---|---|---|
| **书法字砸屏**（既有） | 金粉书法/水墨笔触、招式名 | 武道正拍、认真开大、招式名（一拳一个墨点） | 水墨魂 |
| **3D 立体拟声词**（本件新增） | 立体厚度+网点+撞色描边，音效字（砰/哐/轰/啵/咔） | 高燃反打、卡牌/道具命中、喜剧打斗、赛博技能爆发 | 涂鸦彩墨肉＋赛博骨 |
| **屏内 AR 系统字**（既有） | 等宽字体、L角框、报错/提示 | 面板、属性点、器灵读数、系统提示 | 赛博骨 |

> 一句口诀：**喊招式名→书法字（水墨）；打击音效→3D 拟声词（涂鸦）；系统读数→AR 等宽字（赛博）**。同一拍最多出现两类，三类不叠屏。

### 1.2 3D 拟声词六要素（出图/分镜直接用）
1. **立体厚度**：2.5D 厚度面＋透视倾角，斜冲出画面，不是平面贴纸；
2. **撞色渐变**：字面用 CMYK 式多色渐变（主色＝攻击色，见 1.3）；
3. **halftone 印刷网点**：字面铺一层规则网点，强化波普/漫画印刷感；
4. **多层描边**：主色描边＋对比色外描边（深色勾边保证白天背景也跳得出来）；
5. **撕裂外缘**：锯齿/星形/三角爆点/不规则撕裂边缘，跟随冲击方向；
6. **分级**：大绝招（终结/爆点）拟声词**占满整屏**；普通命中局部小拟声词（不遮脸）。

### 1.3 颜色绑定（沿用本项目既定配色，不新增色板）
- 徐琨认真拳/暗金气血 → **暗金＋焦墨**描边（拟声词偏厚重复古，少荧光）；
- 徐琨暴食/进化/巨人虚影 → **荧光黄绿＋青**描边（涂鸦签名色，喜感/高燃）；
- 徐芸芸深红加点/氪金 → **深红/品红**描边（数字爆点同步）；
- 秦天/危险/警报 → **品红＋黑**；
- 冷蓝血脉/协会/通天塔 → **冷蓝/白金/黑金**描边；
- 拟声词颜色与当次能量色一致，**一次一个主色**，避免满屏彩虹。

### 1.4 出现/消失拍（约 4–8 帧）
弹出（0–2 帧，随打击瞬间砸入、轻微过冲）→ 定格（2–3 帧，可加 1 帧黑白闪）→ 撕裂/网点消散（2–3 帧，随冲击波方向碎开）。与打击点、顿帧严格对齐。

## 二、径向速度线能量过场（进系统 / 觉醒 / 切换状态）

### 2.1 四件套（纯抽象，不依赖场景，可独立复用）
1. **几何破碎爆发**：当前空间裂成发光多边形碎片迸散（线框＋切面）；
2. **径向速度线隧道**：从画面中心向外放射的速度线（**放射，不是横向**），中心留光核，制造"被吸入/下坠/穿越"纵深；
3. **角色色差描边＋残影**：角色在中心坠落/翻滚，轮廓裹主色描边、肢体拖多重残影（RGB 色差）；
4. **色温渐变回现实**：隧道色随段落从"系统色"过渡到现实色温，角色落回真实空间，描边逐帧消退。

### 2.2 本项目落点与换色（对齐四系）
| 落点 | 隧道主色 | 描边残影 | 现实色温 |
|---|---|---|---|
| 暴食激活 / 气海"饿" | 荧光黄绿→惨绿 | 黄绿/青 | 暖白天光 |
| 进化 / 巨人虚影拔高 | 蓝白电光→冷蓝 | 蓝/金 | 暖白天光 |
| 徐芸芸加点结算 | 深红/品红 | 品红/红 | 暖白天光 |
| 通天塔 / 器灵空间 | 黑金＋金符文 | 冷青/金 | 塔内冷光 |
| 信号受损 / 盲区 | 全 RGB 故障撕裂 | 青紫错位 | 切回正常 |

> 白天都市注意：隧道可用**浅底/高亮度**版本（白金光核＋彩线），不必做成黑底夜隧道；镜头光晕、粒子在明亮背景下用加色发光。

### 2.3 时长与节奏
标准过场 **1.5–2 秒（约 36–48 帧）**：破碎 6–8 帧 → 隧道翻滚 18–24 帧 → 渐变回现实 8–12 帧。一集内不连用，避免疲劳。

## 三、撞色能量打斗画法（赛博/异能能量的统一语法）

### 3.1 能量五件套
1. **能量本体＝柔边有机流体色块**：泼溅/气浪/半透明、同色系（如荧光黄绿的流体、蓝白电光团）；
2. **撞击碎片＝硬边几何方块/菱形**：高饱和互补色、切面晶体感（与柔边形成软硬对比）；
3. **运动轨迹＝同色系弧线光带**：青蓝/黄绿等描边弧，标出出拳/挥击方向；
4. **命中＝3D 拟声词＋顿帧**（见第一节）；
5. **余波＝图形化纯色云浪**：深浅纯色云形/浪涛吞没敌人，**不画火、不画黑烟、不写实破坏**；消亡用粒子化（沿用本库铁则）。

### 3.2 铁律：柔边＋硬边混搭
- 只用流体光会"糊"、只用几何碎片会"碎"；**柔边流体（主）＋硬边几何（点缀）**才有层次。
- 一次攻击锁**一个主色＋一组互补色**：例 徐琨暴食＝荧光黄绿流体（柔边）＋品红/蓝碎片（硬边）＋青绿弧线；秦天＝品红流体＋黑/青碎片。
- 武器/巨拳与能量互补撞色参考：冷金属（银灰）× 高饱和能量（黄绿/蓝白）。

### 3.3 巨人化重量感叠加（本书武戏铁则，不丢）
- 赛博/卡通能量之外，徐琨巨人线必须保留**地面塌陷、冲击波、长投影、体型参照**（武戏库）；
- 卡通能量用于"轻快高燃/系统技能/喜剧反打"，**认真爆城/法相正拍转暗金泼墨/水墨**，不 Q 化（沿用风格件执行规范 4）。

## 四、游戏化技能 UI 视觉皮肤（外观规格；功能见技能装备库）

> 所有 UI 一律套本项目 AR/HUD 语言：**半透明卡片、扫描线、加载环、网格、悬浮窗边缘光、L 型括号角框、等宽字体**；禁古风卷轴。

### 4.1 圆形技能盘 / 光轮
- 形态：外圈发光环（主色）→ 内圈细分段/跑马灯 → 中心徽字/图标（汉字/数字/符号）；
- 起手/觉醒时浮在角色身前或环绕，激活时微金边（血脉口径）；
- 配色按所属系：血脉冷蓝白、加点深红、协会白金、通天塔黑金。

### 4.2 道具/技能卡
- 形态：**发光描边框＋方形内圆角＋半透底（扫描线/网格）＋内绘技能/道具图标＋角标等级/数值**；
- 战斗中悬浮角色身侧、可实时翻牌；卡间用等宽字体标名称/代价（代价用项目自有：属性点/能量/暴食层数/积分，**不出现标价/抽卡词**）。

### 4.3 卡牌实体化（2D 卡 → 3D 物）
- 卡片在手中碎成主色几何碎片＋光晕，技能/武器/召唤物从碎片中"长出"真实 3D 形态；
- 过渡 4–8 帧，伴随短促提示音（见声音结构/能力音）。

### 4.4 晶体护盾 / 格挡
- **多边形切面晶体＋可见线框顶点**，半透明、硬几何；格挡时受击点亮、裂纹沿切面扩散；
- 格挡音效可用小拟声词（局部、不占屏）。

### 4.5 技能徽章环 / 状态槽
- 多个彩色圆徽章环绕角色肩/腕（灵环投影位置），表"已装备/可用技能槽"，激活态亮、冷却态灰；
- 徽章颜色＝技能/角色签名色，保持全片统一。

### 4.6 系统界面实体化"大招装置"（最高仪式）
- 形态：**铺场媒介 → 脚下法阵/光圈 → 角色站中心 → 身后展开巨型全息系统界面**，外圈一整圈功能灯牌/符号；
- 本项目换皮（不照搬转盘/商店）：做成**巨型 AR 全息阵图/通天塔考榜/血脉谱系轮/数据面板矩阵**等，外圈灯牌＝项目自有的功能项（属性、血脉、器灵、层数、战绩等），跑马灯用全息光带/数据流而非霓虹灯泡；
- 白天环境下装置用**全息半透明＋发光描边**，金/白金光做仪式感，避免夜市霓虹的夜场质感。

### 4.7 标题 / 大字演绎
- 关键标题/技能名可做**全息 3D 立体字＋故障 glitch（水平切条/错位/RGB 色差/扫描线）＋逐字飞入定格**；
- 武道招式名仍走书法（水墨），系统名/关卡名/赛博称号走全息故障字。

### 4.8 波普放射板与 2D/3D 混用（喜剧/高燃可选）
- 高燃/喜剧拍可在 3D 角色身后插**平面波普放射板/纯色块**（涂鸦彩墨层），做夸张表情与强透视；
- 战斗高光正拍、水墨正拍不插波普板；每层不得连续垄断（沿用风格件执行规范 1）。

## 六、卡通打斗视觉补充（波普炸入 / Q版帧 / 败北云海）

> 源拉片波普爆炸开场、红布翻滚、绿爆云海吞敌段。全部归涂鸦彩墨层；镜头节奏查武戏库第五、六节。

### 6.1 波普炸入（开场/转场冲击图形）
- 形态：锯齿星形爆口＋CMYK 错位＋霓虹点阵，从画面中心炸开，人物从破口摔入/冲入；
- 用途：喜剧打斗段开场、高燃反打入场、场景硬切转场；**不用于正拍击杀**；
- 时长 6–10 帧，颜色取当段主色＋一组互补色，不给彩虹杂色。

### 6.2 2D/3D 混用语法
- 3D 角色身后可插**平面波普放射板/纯色块/2D 速度线背景**做夸张表情与强透视拍；
- 插板只停 1 个镜头（2–8 帧），随切镜消失，不与同场景写实镜头连用超两次。

### 6.3 Q版/符号化点缀帧
- 半秒内的 Q 版表情帧：星星眼/蚊香转圈眼/头顶喷漆"爆"字/无语蓝框定格/懵"？？"（符号库沿用风格升级件欢快感引擎与鱼太保弹窗）；
- 只做 1–2 帧点缀或反应镜头，**主角认真态、击杀态禁用**。

### 6.4 卡通受击与败北云海
- **受击三件**：2D 团状白烟＋杂物沿冲击方向飞出＋长翻滚拖速度线，不见血；
- **掀飞轨迹**：沿攻击方向划可见抛物线，空中翻 1.5–3 圈，可配小拟声词；
- **败北云海**：深浅同色纯色云浪吞没有序伸出的手脚/兵器，退浪后敌人挂墙头/嵌地面/摞成堆，或给蚊香眼/趴平符号；
- 云海不画火、不画黑烟、不写实破坏（沿用 3.3 铁律）。

### 6.5 空战卡通拍
- 离镜：2D 放射速度线＋人物缩 Q 版小质点；空中翻滚多轴线、四肢张开，失重顶点 0.5 拍定格夸张表情；
- 缓冲落地：团尘长滚／布裹团滚／连穿杂物逐件减速，三选一；
- **徐琨例外**：重量型选手不做摔狼狈——空中从容（进食/打哈欠/指路），喜剧反应放地面与他人，体型参照/长投影照给。

### 6.6 卡通层退出信号
- 进入认真击杀/法相/死亡拍：色彩瞬间抽饱和、音效骤静一拍，涂鸦元素（拟声词/波普板/Q版）即时退出，交暗金泼墨与水墨；
- 反向回归（正拍结束回到轻松段）：用一枚小拟声词或鱼太保弹窗做"再入场"，不直接硬切。
