# 场景固定设定 · 北辰武馆

> 首次出现：S1-EP3；EP4–EP6 持续复用。江东市排名前三的顶级私立武馆。

## 固定场景设定

- **大门**：占地极广、气势磅礴；金属质感与力量感，巨幅落地窗，馆名光效；VIP 人脸闸机。
- **大厅**：招生季人潮；悬浮导览屏、电子报名台；普通长队与 VIP 通道分流。
- **综合测试区**：重型拳力测试机（合金靶、联网成绩）、光栅计时跑道（0.01 秒精度）、负重跑步机（心率直连监控大屏）、光栅跳垫、教官电子记录板；历史数据可随时调取对比。
- **自助餐厅**：五星级酒店级；异兽肉分区保温、食材带能级标签；冷链补给口；机械厨师辅助。教官手环可看累计市价（喜剧计费）。
- **C 区训练馆**：编队教学、统一练功服、教官教鞭。
- **重力室 / 核心训练区**：面板调节倍数；室内重力压迫光效。
- **淬体实验室**：高三米圆柱形透明淬体舱，周接管道与仪表盘；药液加压渗透、屏显实时吸收效率。
- **馆主办公室（顶楼）**：落地窗俯瞰全城；全息合约可翻页 + 鎏金纸质合约并存；文件带 S 级机密标识。

## 道具补充

- 家用 / 训练用粗大金属注射器与安瓿瓶（喜剧道具）。
