# 场景固定设定 · 江东市总设定（环壁都市）

> 权威来源：《世界观细化_赛博灵气·S1.md》王导已拍板。同城市任一场景重复出现时，本文件相关条目一字不差复制。

## 一、城市定位

- 蓝星 · 华夏联邦 · 江南大区重要**环壁都市**，人口千万级；第一季唯一主城地图。
- 约百年前灵气复苏，人类借灵气能源与异兽材料把科技点到超过旧时代；城市之外的荒野区是怪兽与旧时代废墟的天下。
- 社会基调：霓虹、全息、无人系统高度繁华；城市之外即是死亡，武者为最高阶级。赛博生活的破事（网贷、杀熟、认证失败、售后扯皮）原封长在高武社会里。

## 二、环壁都市三层结构（固定）

| 圈层 | 固定设定 |
|---|---|
| **外环防御带（环壁）** | 高约百米的合金城墙，墙体蚀刻阵纹电路、嵌入防空激光炮阵与能量盾发生器；墙外即荒野区；墙顶是城防军巡逻道。城墙只防地面，**空中无永久穹顶**，仅战时拉起局部能量拦截网。 |
| **主城** | 若干城区，摩天楼群、立体交通、全息街区、磁轨列车线；老小区与新摩天楼并存。 |
| **内环（权力核心）** | 市政大楼、武道协会总部、通天广场与通天塔。 |

> **因果铁律**：环壁只防地面兽潮，飞行异兽可越过城墙——飞行异兽突破防空网后即可直扑主城街道，这是环壁都市唯一正面破口。

## 三、灵气 × 科技融合原理（视觉一致性根基）

灵气是可被仪表测量的能源（灵气浓度、灵子指数均有读数）：

1. 能源：灵气充电 / 灵子电池 / 充电桩；阵纹蚀刻在电路板上（"阵法电路"），能量盾、激光阵靠灵子供能。
2. 材料：异兽是工业原料——鳞甲进合金配方，兽血做针剂与营养液，妖丹是电池核心。
3. 三条路线并行：传统线（丹药 / 御剑 / 拳法 / 符箓）＋科技线（针剂 / 飞行器 / 外骨骼 / 芯片）＋杂交主流（符箓芯片、纳米法器、电磁阵纹武器）。
4. 武道可被仪器量化：气血值、拳力、战力评级均可测；所有"系统面板"视觉本质都是**量化仪表的 AR 成像**。

## 四、城市风貌（固定背景元素）

- **天际线**：数百米至千米摩天楼群，楼体全息广告如河水流动；空中轻轨穿梭楼宇；夜雾、霓虹、雨水反光为赛博底色。
- **地面**：无人出租车与巴士（方向盘可收起）、电助力共享单车站、机械臂摊贩、自动贩卖机矩阵、无人配送机航线、人脸识别闸机、巡逻无人机、电子站牌、分拣机器人。
- **立体交通分层**：物流层 / 车行层 / 空中管制层；私人飞行器受限，空中以军方、急救、物流为主。
- **城际**：磁悬浮高铁。
- **质感**：灵子电站、充电桩林立；旧电线、老招牌与全息屏并存，制造年代层叠。

## 五、防空体系（空袭专用固定道具）

- 警报塔、街区广播大喇叭、应急避难引导光带、楼顶激光防空炮阵列、拦截导弹巢。
- 空袭流程固定：警报塔声光大作 → 手环 / 电视 / 楼宇屏全部切入警报弹窗、街道广播循环 → 防空激光炮与拦截导弹开火、空中亮起能量拦截网 → 部分飞行异兽被击落、部分低空突破下沉进城。

## 六、社会组织的科技细节（背景随时取用）

- 证书配色：初级武者蓝本 → 中级紫本 → 高级红本烫金 → 宗师黑皮烫金；津贴自动到账，特权清单全部 APP 化。
- 城防军指挥中心：巨屏矩阵，荒野热成像、兽潮红点实时刷新。
- 一级战备：征召令一键推送所有注册武者终端。
- 金融：武道银行武者低息贷款；民间算法网贷向学生精准营销。
- 媒体：全息新闻、全民短视频直播、弹幕空间可视化。
