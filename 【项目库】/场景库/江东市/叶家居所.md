# 场景固定设定 · 叶家居所

> 含：叶家庄园（EP7）、天澜湾·叶清漪别墅（EP6）、市长官邸（EP8）。

## 叶家庄园（叶天南）

- 中式豪门：红木厅、名贵红木茶桌、私家侦探照片墙（长焦 / 无人机偷拍视角：街头喝奶茶、机车后座、会所出入）。
- 叶天南书房可远程查分：拨打电话 + 屏幕同步教育局数据。
- 核心道具镜头：结婚证红本滑过红木桌面。

## 天澜湾 · 叶清漪私人别墅

- 巨大客厅被改成私人综合训练场：专业防震地面、重力调节器、全息投影对战台、合金木人桩、满墙剑架（长剑 / 短剑 / 重剑 / 软剑）、医疗修复舱。
- 巨型双开门冰柜：冷储密密麻麻的针剂、药液与异兽血肉（蓝鲸髓液、基因强化剂、龙血草提取物）。
- 高量程测力器。

## 市长官邸（宋婉词 / 糖糖）

- 内环附近独栋庄园，庭院带修剪整齐的草坪。
- 院内可架烧烤架；EP8 空袭后魔鹫尸体置于院中。
- 室内餐厅：后厨冷库可被清空（喜剧计费）。
