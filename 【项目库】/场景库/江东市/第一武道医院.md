# 场景固定设定 · 江东市第一武道医院

> 首次出现：S1-EP9（高考体检）。

## 固定场景设定

- **大门外**：各校校车排长龙；学生队列。
- **大厅**：电子叫号屏、消毒雾、空气弥漫消毒水与淡淡血腥气；急诊担架车不断推过（断肢、腐蚀伤、反折腿伤的前线武者）；电视墙播前线消息。
- **专家诊室**：检查床、人体扫描仪（红外全身扫描、语音播报身高体重）、电子病历屏。
- 检查手段可视化：医疗真气（灵枢之手）、显微仪器、微观瞳术视野 UI；医生知识库可弹红色警告。
- 针头固定设定：武者皮肤普通针扎不破，须用合金特种针头、运真气刺入；血液粘稠、离体微泛金光。

## 镜头可用元素

- 扫描仪红色数据刷满屏；血脉浓度读数一路冲到 99.999%。
- 微观 UI 里：燃烧如小太阳的血细胞、基因链中咆哮的巨人虚影、金色光辉下极淡的紫气（超凡因子）。
- 红色报错框："警告！检测到高能反应｜特征匹配：超凡因子！"
