# 武戏库

> 按战斗类型记录镜头公式、运镜、节奏、音效；精彩片段标注集 / 单元回写于此。

## 分类骨架（随创作填充）

| 类型 | 适用 | 镜头要点（待补） |
|---|---|---|
| 近身格斗 | 徐琨纯肉身、以力证道 | 拳拳到肉、重量感、顿帧 |
| 异兽 / 兽潮 | 荒野、守城 | 群像 + 规模 + 个体高光 |
| 武道法相对轰 | 大圣 / 武皇以上 | 巨型化身、内景外显 |
| 巨人爆城 / 爆星 | 成长后 | 体型参照、破坏分级 |
| 空战 / 飞行 | 魔鹫、羽皇、月域 | 立体机动、跟拍 |
| 追杀 / 突围 | 北伐、救人 | 一镜到底、节奏波形 |
| 游戏化系统技能 / 赛博异能 | 暴食/进化/加点/召唤/系统大招 | 实时翻牌选技能、卡牌实体化、3D拟声词、撞色能量、系统界面实体化 |

## 本书武戏铁则
- 每个成长阶段给体型参照镜头；巨人动作要有地面塌陷 / 冲击波 / 长投影。
- 纯肉身路线：少花哨法则，多力量与重量表现。
- 消亡用粒子化，不渲染血腥。

## 一、游戏化技能 / 超凡技释放（七拍）

> 适用：徐琨暴食/进化、徐芸芸加点、各类"喊名技能/召唤/系统技能"高燃反打。
> 视觉皮肤（技能盘/卡牌/拟声词颜色）见美术库《游戏化赛博特效_3D拟声词与能量过场》；本节只管镜头、运镜、节奏。

| 拍 | 内容 | 镜头/运镜 | 节奏 |
|---|---|---|---|
| ①压场 | 大全景对峙：徐琨（背影/小体量）vs 兽潮/强敌，制造强弱悬殊 | 大全景缓推或静帧 1–1.5 秒 | 静 |
| ②高手 pose | 回身、手遮眼只露嘴角、戳太阳穴、歪头笑，停顿半拍 | 近景/特写，浅景深静止 | 顿 |
| ③调技能 | 灵环/腕部 AR 投影，身前浮圆形技能盘/光轮、肩侧技能徽章环 | 手部/胸前特写＋环绕半弧 | 起 |
| ④翻牌选定 | 技能/道具卡实时翻牌，角标跳代价（暴食层数/属性点/能量）；敌人照打、徐琨从容选 | 卡牌特写正打＋敌人虚焦侧打交叉 | 反差喜感 |
| ⑤实体化 | 卡牌碎成主色几何碎片＋光晕，技能/武器/召唤物（暴食怪嘴、巨人虚影、蓝金进化光柱）从碎片中长出 | 升格（慢镜）4–8 帧，由卡及物拉镜 | 蓄 |
| ⑥命中 | 3D 拟声词（喊名同步）＋顿帧＋柔边流体＋硬边几何碎片＋同色弧线 | 打击点顿帧 2–3 帧＋可选 1 帧黑白闪＋冲击帧 | 爆 |
| ⑦余波定格 | 纯色云浪/暗金泼墨吞没敌人，敌人掀飞；徐琨定格 pose，书法招式名或全息系统字收束 | 俯拍大全景→角色定格特写 | 收 |

- 喊名规则：**喊招式名→书法字砸屏（水墨）；打击音效→3D 拟声词（涂鸦）；系统读数→AR 等宽字（赛博）**，同一拍不叠三类。
- 反差点：第④拍"敌人围殴、主角却在慢悠悠翻牌/看代价"是核心喜感，镜头给足从容，到⑥再爆发。

## 二、系统界面实体化大招（终结/必杀最高仪式）

> 把抽象能力做成"压在身后的巨型全息装置"。本项目**不使用转盘/商店/抽卡灯牌**，替换为自有体系。

**五拍结构**
1. **铺场**：灵环/空间戒指投影，脚下向四周扩散 AR 全息阵图（或地面暗金法阵），镜头俯拍；
2. **站心**：徐琨走到阵图中心，脚下冷蓝/暗金光圈逐层亮起，长投影；
3. **装置展开**：身后升起巨型全息实体——按体系选：**血脉谱系轮 / 通天塔考榜 / 数据面板矩阵 / 暴食巨兽虚影**；外圈一圈功能灯牌（层数/属性/血脉/器灵/战绩/称号），用全息光带＋数据流，不用霓虹灯泡；
4. **选定聚光**：某一扇区/条目被锁定高亮，光柱垂下，径向速度线向中心汇聚（接美术库能量过场）；
5. **一击爆发**：锁定结果化作全力一击（巨人虚影/暗金神火/法相），3D 拟声词占满屏＋纯色云浪→粒子化，定格收尾。

- 镜头：俯拍铺场（交代装置规模）→ 低角度仰拍（装置压顶、人小阵大）→ 绕人半弧（人阵合一）→ 爆发定格。
- 时长：铺场 0.5s＋装置展开 1–1.5s＋锁定聚光 0.5s＋爆发 0.5s，全段约 3–4 秒，只在关键集/终结用。
- 白天落地：装置用全息半透明＋发光描边，金/白金光做仪式感，不做夜场霓虹。

## 三、撞色能量打斗（赛博异能能量）

**五拍节奏**：聚气（径向速度线/能量盘转）→ 出手（同色弧线轨迹跟拍）→ 接触（顿帧＋黑白闪＋3D拟声词）→ 爆发（柔边流体主色＋硬边几何互补碎片）→ 余波（纯色云浪吞没、敌人掀飞）。
- 铁律：**柔边流体＋硬边几何混搭**（只用流体糊、只用碎片碎）；一次攻击锁一个主色＋一组互补色。
- 徐琨暴食/进化：荧光黄绿流体＋品红/蓝碎片；认真爆城转暗金泼墨/水墨；徐芸芸：深红/品红。
- 不画火/黑烟/写实破坏，冲击波用纯色图形化云浪；消亡粒子化。
- 巨人线必须叠加重量三件套（地面塌陷/冲击波/长投影），能量再炫也不丢"大"。

## 四、卡通物理与高燃反差（轻打斗 / 喜剧）

- **团状尘云**：落地/受击用 2D 团状白烟，不写实扬尘；
- **杂物飞溅**：砖石/瓦片/课桌/物件沿冲击方向飞出；
- **长翻滚/贴地滑行**：受击拖长速度线、撞翻物件，喜剧化处理摔伤；
- **强透视**：冲向镜头的拳/手/道具画大（广角），破壁拉客感；
- **夸张表情＋定格 pose**：瞪眼、闭眼笑、戳太阳穴、竖大拇指、手遮眼只露笑；
- **多格漫画快切**：收尾连续切多个机位，像漫画分镜，制造"帅气收尾"。
- **道具一物多用**：同一件道具一场戏里至少变形两次——投掷武器 → 受击裹身缓冲团 → 披风/铺场仪式布（拉片红布公式）。徐琨线从**已有道具**取材（校服外套/饭盆/招生横幅/旧海报），不新增神器、不改变道具功能。
- **敌人卡通败北图鉴**：掀飞沿攻击方向划可见弧线、空中翻 1.5–3 圈配小拟声词；群体败北用纯色云浪吞没、浪里有序伸出手脚/兵器，退浪后挂墙头/嵌地面/摞成堆；伤害符号化（蚊香眼/转圈眼/星星/Q版趴平），不写血不写实残伤。
- 适用：徐琨日常/校园/市井/高燃反打/系统技能；**战斗高光正拍（爆城/法相/认真击杀）用水墨/泼墨，不卡通化**。

## 五、卡通空战与立体机动（空中喜剧感）

> 源拉片屋顶追逐/红链锯/空中翻牌/红布裹身翻滚段。空战类型（魔鹫/羽皇/月域）的正拍仍走立体机动跟拍与重量感，本节只管其中的**卡通喜剧拍与过场拍**。

1. **离镜**：被击/起跳瞬间 2D 放射速度线＋"咻"类小拟声词，人物可缩成 Q 版小质点飞出画。
2. **空中姿态滑稽轮廓**：翻滚走多轴线（侧翻/前滚/大字摆），四肢张开；失重顶点给 0.5 拍**定格表情**（瞪眼/嘴张成 O），且手里道具不撒手（还攥着饭盆/食物——人设笑点不断线）。
3. **危险照打、忙别的**：空中/被追中回身照常做从容动作（回身指点追兵砸出拟声词、空中翻牌选技能），越危险越淡定是核心反差。
4. **缓冲落地三选一**：①团状尘云＋长翻滚卸力；②布状物裹身成团滚到停再展开（拉片红布公式）；③连续砸穿一串杂物（雨棚/货架/课桌/摊位）逐件减速。伤卡通化、不见血。
5. **立体机动机位**：穿越机环绕＋**缓慢翻滚镜头**（翻镜头不翻人，观众不晕）；墙面奔跑斜 70 度持续线；落点先给脚部特写（脚尖点→脚跟压→膝卸力）再接全身。
6. **徐琨特例（重量型选手不摔狼狈）**：他空中永远从容（吃东西/打哈欠/随手指路），笑点放在**地面和别人身上**——他还没落，人群/摊位/地砖已经先遭殃；体型参照与长投影照给，"大"不丢。
7. 空战中遇技能释放，直接接第一节七拍；遇认真击杀，退出卡通拍转水墨。

## 六、以一敌百 · 卡通打斗整场波形（打架的"感觉"总谱）

> 源拉片 66 秒 PV 完整节奏。写整段喜剧/高燃打斗时按此波形铺，不只套单个招式。

1. **炸入**：波普爆炸图形/撞色冲击帧开场（锯齿星形＋CMYK 错位＋网点），不做写实静开场。
2. **叫卖式亮相**：强透视大手/道具直冲镜头＋夸张表情定格半拍（徐琨版：举饭盆/戴拳套/鱼太保弹窗抢话）。
3. **先挨一下**：被强敌拍飞 → 灰暗降饱和闪回半秒（动机/家人，不超 1 秒）→ 团尘翻滚起身，不流血。
4. **追逐立体段**：巷战/屋顶/走廊/操场，机位点逐拍换（围墙/雨棚/课桌/摊位/球架），不重复同一背景两拍以上。
5. **亮盘**：技能盘首现＋径向速度线隧道过场（状态切换仪式，见美术库第二节）。
6. **反差选技能**：被围当中从容翻牌/看代价/吃东西/算账（核心喜感拍，时长给足，敌人照打）。
7. **连打**：技能/道具实体化后连发连扔，**每击一个拟声词、一种颜色**，机位多格漫画式快切；同一种打击方式不连用超过两次。
8. **道具变形**：第四节"道具一物多用"在此兑现（攻→防→仪式）。
9. **压场半拍**：大全景敌阵压境＋背影小体量＋手遮眼只露嘴角笑，静 1 拍。
10. **开大收束**：铺场 → 系统实体化大招（第二节）→ 纯色云海吞敌 → 定格 pose＋书法招式名或全息系统字。

- **节奏铁律**：炸（开场）→快（追逐）→炫（过场/亮盘）→松（反差选技能）→爆（连打）→压（对峙）→开（大招）。每 8–12 秒必须给一个新视觉元素（新道具/新拟声词/新机位/新表情），同段不复读。
- **视觉总量控制**：卡通打斗"动作不停、信息不停"，但一次攻击一个主色＋一组互补色；满屏色块/占屏拟声词只给爆点拍与终结拍，连续小招用局部小拟声词，避免审美疲劳。
- **正拍退出点**：波形中一旦进入认真击杀/爆城/法相/死亡相关拍，涂鸦层立即退出，交暗金泼墨与水墨（风格升级件执行规范 4）；退出可由"色彩瞬间抽饱和＋音效骤静"做切换。
