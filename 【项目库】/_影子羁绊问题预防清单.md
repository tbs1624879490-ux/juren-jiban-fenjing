## A. 写实铁律（正文层）

| # | 影子羁绊教训 | 本项目防线 |
|---|---|---|
| A1 | 参照空指针：甩"单元X/AT-编号"不写内容（用户骂过 6 次） | 已立【单元独立写实铁律】；正文只写实拍内容，编号只在内部台账 |
| A2 | 元指令混入正文：篇章/时长/承接/"这句给谁看"泄漏进分镜 | 创作管理信息只进文末备注区，正文零残留【机】 |
| A3 | 解释性批注（【因果】【手法内化】）混入正文 | 同上，手法说明全部进备注；正文只留画面 |
| A4 | 正文写角色外观/面罩材质，覆盖建模（角色卡被推翻） | 分镜层角色外观一律以角色卡+描述词库为准，正文只写形态节点/动作/微表情 |
| A5 | 否定式无效词（"无黑眼圈/没有眼袋"）；视频模型读否定句有害 | 全部正向写法：写"有什么"，不写"没什么"【机】 |
| A6 | 借排版连内容字一起抄（抄了"修炼日记"字样） | 借排版只借版式，内容字样逐字替换 |
| A7 | 角色错名（陆瑶瑶/路遥遥） | 正名表锁定：徐琨/叶清漪/徐芸芸/糖糖/宋婉词/罗峰/林万钧/沈冰/秦天/玉萝/陈震南/苏清歌【机】 |
| A8 | 多主体场景用"自己/他/她"指代不清 | 多人同场一律正名 |
| A9 | 场景写成地点名词清单 | 场景段=动线+材质+光源方向+地面反射+外景动态，从描述词库整段取用 |
| A10 | 评价词（"高端/大气"）无画面 | 一律具象参照（"像高端博物馆"→写博物馆的具体质感） |
| A11 | 台词烫嘴、一镜塞多句 | 一镜一句口白；超长必拆镜 |
| A12 | OS 旁白解说替代表演 | 能用动作/微表情演的，删 OS（嘴闭上手在戏） |

## B. 武戏物理与打击感（分镜层 · S1 空袭/杀秦天/玉萝/塔内战）

| # | 教训 | 防线 |
|---|---|---|
| B1 | 摆荡写成"一直飞"（用户震怒）：必须以影丝与墙面接触点为圆心轴、丝为半径、人沿圆弧荡 | 本项目一切空中位移必须有物理轴：御剑=足踏飞剑受力于剑身；跳跃=起跳轨迹向下落；绝不无轴悬浮 |
| B2 | 姿态错：滑翔写成直立/垂直下坠 | 滑翔=胸腹朝下、身体与地面平行、张臂；下坠轨迹持续向下 |
| B3 | 变身因果丢失（瞳变→覆盖→影现→影裹→燃身，走完才可用能力） | 巨人发力链固定：暗金流光起→拳锋/足下高光→金色粒子→出手；没走完不放招 |
| B4 | 动作链拆断、只写结果 | 过程一拍不许缺：蓄力→爆发→命中→反馈→余韵五拍 |
| B5 | 爪光空抓（打击没打在身上） | 每道光/每拳必中目标+受击反应同框【机：命中词后必须有受击描述】 |
| B6 | 打击无代价（挨打只"一震"） | 命中后续必有代价：踉跄/退步/闷哼/护甲碎/武器脱手/砸物【机】 |
| B7 | 敌方行为不合理（站着挨打不反击） | 怪物会反击、重伤会怒吼、异种按体态行动（跛行慢）；徐琨挨打同样有代价 |
| B8 | 高速段缺前景遮罩 | 凡高速位移/战斗段落，前景遮罩写进画面（掠过的钢筋/雨幕/广告牌碎片） |
| B9 | 缺冲击帧、缺方向反制 | 受击瞬间插1–2帧黑白冲击帧；"打东割西"方向反制造层次 |
| B10 | 终结无逻辑（定格莫名其妙）；收招无终点 | 终结三件套=升格慢镜姿势→致命一击→结果（化雾/坠地/砸坑）；收招固定终点（吸收→固定落点，如胸口纹身式） |
| B11 | 武戏全是定机位单镜（用户："为什么不是运动镜头？"） | 武戏以运动镜头为主（景别写"起→落"链：中景→特写、近景→大特写）；定机位仅限冲击帧/骤静/收势/UI结算 |
| B12 | 景别扛不下动作（近景硬扛肢体调度） | 肢体互动用中景/中近景；近景只到胸上 |
| B13 | 同档硬切（中景接中景=同画缩放） | 相邻镜景别必跳档或插空镜/道具特写 |
| B14 | 特写一镜装三名说话人 | 多人对话拆正反打或改中景+横摇 |
| B15 | 穿插密度不够（用户："至少高十倍"） | 瞬闪连击段：现身5–10次、每爪1–3道光、光痕累积成网；节奏只快不拖 |
| B16 | 用词错（是爪写成刃） | 打击词汇精确：爪光/拳劲/刀光不得混用 |
| B17 | 信息密度松（用户："密度有点松"） | 每镜六要素铺满，物件颗粒上下统一；删注水镜 |
| B18 | 固定镜数凑数（"为什么固定4镜？"） | 镜数由内容密度决定，不为格式凑数 |

## C. 世界观与视觉统一

| # | 教训 | 防线 |
|---|---|---|
| C1 | 场景光源违设（暗面世界写出楼窗亮灯） | 夜戏光源从场景库照抄（如徐家客厅主光=吊灯+窗外霓虹）；不得私自加灯 |

| C7 | 美术登记/色调标准批量时 100% 被跳过 | 每单元头部必写色调标准+光源（分镜阶段设为交付门，缺=打回）【机】 |

## E. 生产流程机制

| # | 教训 | 防线 |

| E1 | 批量产出跳步骤（美术登记全跳过） | 分镜批量前先出**武戏手法排布表**（每10–20单元一张，王导确认后开写） |

## F. 因果链铁律（每个关键动作）

```
① 刺激先入画（因）→ ② 反应与判断（桥）→ ③ 动机自明（据）
→ ④ 动作发生（果）→ ⑤ 动作有结果（收）
病灶：因果倒置 / 完全无因 / 跨镜断链
豁免：纯空镜；OS 已交代动机且写明目标
```
- 典型病灶（影子羁绊实例）：听到声音→躲，缺中间"耳廓一动、脚步一顿"反应拍。
- 本项目自查句式："他为什么此刻做这个？"答不上=回炉。
