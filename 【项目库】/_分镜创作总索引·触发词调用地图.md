## 一、使用流程

1. 从需求 + 单元的【主体动态】【场景环境】【台词 OS】【全局铁律】提取关键词。
2. 对照下表触发域逐一命中；命中即 Read 对应文件，落实动作 / 镜头 / 光影 / 音效 / 人设细节。
3. 多词叠加；过第三节"通用必调清单"与四项叙事前置。
4. 改编任务再叠加《改编总方案》与对应段《编剧意见单》。

## 三、通用必调清单

- 人设（语言风格 / 微表情 / 禁用演法）、场景四要素、天光时段、主类型、技能、美术、故事线进度、动作链、三层环境音。
- 四项叙事前置：①本单元冷开场类型与 ED 钩；②母题回环点；③伏笔前置状态；④（改编）章节映射与四类操作（拆分 / 合并 / 前移 / 原创）。

## 四、卡片参考触发域

- 有卡人物 / 异种 / 场景 / 道具出场即锚定参考卡：分镜只写动作 / 微表情 / 光效 / 镜头，卡覆盖的外观本体与穿着不写；无卡路人才描述外观。

## 五、回写闭环

- 用户认可的精彩段落、新梗、新拉片规则，追加到对应库并在本地图登记触发词。
