## 〇、一句话

把"调技能、加属性、召唤、升级"统一做成**灵环里可见、可点、可拿出实体**的全息交互：
面板选择（2D UI）→ 实体化（3D 能量/武器/虚影）→ 出手命中。让观众"看得见主角在用系统操作"，而不是听旁白。

## 一、五系面板里的"游戏化实体"统一组件

> 所有组件遵守五系既有配色与 L 角框/等宽字体/扫描线，**不出现任何商店、抽奖、标价、商品名**；数值一律用项目自有（属性点/能量/暴食层数/塔层/积分）。

| 组件 | 形态 | 交互/功能 | 适配面板 |
|---|---|---|---|
| **圆形技能盘** | 外圈分段发光环＋中心徽字/图标，浮在身前或绕身 | 起手/觉醒时显示当前可用技能/血脉；选中扇区高亮，激活微金边 | 血脉冷蓝、加点深红、塔黑金 |
| **技能/道具卡** | 发光描边＋方形内圆角＋半透底（扫描线/网格）＋内绘图标＋角标数值 | 战斗中从灵环/光脑实时展开、翻牌选择；角标标消耗/层数/等级；选中后实体化 | 各系沿用底色 |
| **实体化** | 卡碎成主色几何碎片＋光晕，技能/武器/召唤物从碎片中"长出" | 2D 选择 → 3D 实体，是"调系统"和"真出手"的视觉分界 | 随技能色 |
| **技能徽章环** | 多个彩色圆徽章环绕肩/腕（灵环投影位） | 表已装备/冷却技能槽，亮=可用、灰=冷却，切换时徽章翻面 | 各系 |
| **晶体护盾** | 多边形切面＋线框顶点，半透明硬几何 | 格挡/防御技能，受击点亮、裂纹沿切面扩散 | 冷蓝/品红按系 |
| **数值飘字** | 等宽字体、高饱和、固定字号层级 | 力量/属性/伤害/层数/能量在动作旁弹出，可刷屏但不遮脸 | 血脉冷蓝白、加点深红 |
| **系统实体化大招装置** | 铺场阵图→身后巨型全息面板/谱系/榜单 | 终结级把整个系统界面实体化压在身后（见第四节） | 分系统 |

## 二、徐琨 · 巨人血脉线（冷蓝＋暴食能量条）

- **技能盘中心徽字**：血脉（蓝白）/暴食（黄绿怪嘴）/进化（蓝金人形光柱）；激活时微金边、字号巨大、冰冷机械提示音（沿用既定口径）。
- **暴食实体化**：技能卡"暴食"选定 → 黄绿碎片＋惨绿光点 → 怪嘴/巨口虚影在徐琨身前或拳面"长出"，咬合/吞噬获得能量；暴食能量条随之暴涨。
- **进化实体化**：技能卡"进化"选定 → 蓝金碎片 → 人形光柱升级（拔高/体型增长），配合径向速度线过场（美术库第二节）；进化是**成长型因果**，表现为渐进拔高，不做瞬时变身。
- **巨人虚影**：血脉全开时蓝白电光巨人虚影在身后展开（已有设定），可作为"系统实体化大招"的本体之一（见第四节）。
- **徽章环**：肩/腕环绕当前血脉技能徽章，按成长阶段逐个点亮（解锁可视化），不新增技能。
- **气海"饿"字**：惨绿书法字悬浮属水墨层（不在赛博面板里），与冷蓝面板并存，三层对撞。

## 三、徐芸芸 · 深红加点线（氪金手游式 → 本规范的最佳落点）

- 徐芸芸系统**本来就是"充值/加点按钮高亮、数值表格化、像氪金手游"**（既定设定），故"卡牌选择/数值购买/高亮确认"的交互在她这里最自然：
  - **加点卡**：深红/暗红半透面板里，每一项可加属性（力量/体质/速度等）做成一张**可高亮的属性卡**，角标显示所需货币/点数（1 万元=1 属性点的既有换算）；选中→高亮→按下确认→属性生效。
  - **数值爆发**：加点完成时，红色数值在身体/面板上连续跳动、结算飘字（这是"氪金变强"的爽点，用深红/品红拟声词与飘字，不用商品词）。
  - **战斗中调出**：危急时实时翻开属性卡、即时加点反杀（翻牌选属性→实体化生效→身体爆出红色能量），对应武戏库七拍的第④⑤拍。
- **禁止**：不出现"抽卡/十连/免费抽/兑换/转盘/库存/商品"等词；交互可像手游，但语义全部是"属性/加点/货币换算/结算"。

## 四、系统实体化大招（终结级 · 分系统换皮，禁转盘/商店）

> 结构＝铺场阵图→角色站中心→身后巨型全息系统实体→锁定扇区/条目→聚光爆发（镜头见武戏库第二节）。本项目四个合法"装置"：

| 系统 | 巨型装置形态 | 外圈灯牌/扇区（项目自有） | 爆发 |
|---|---|---|---|
| 巨人血脉（徐琨） | **蓝白电光巨人虚影 / 血脉谱系轮盘**（扇区=血脉能力/进化阶段） | 血脉、暴食层数、进化阶段、体型倍率、气血 | 锁定的能力化作巨人一拳/虚影重击 |
| 深红加点（徐芸芸） | **巨型属性矩阵/数值面板**（属性列柱＋结算屏） | 力量/体质/速度等属性、货币、点数、倍率 | 加点拉满的属性瞬间爆发 |
| 通天塔 | **黑金通天塔考榜/全息塔层**（金符文数字、碑刻逐字） | 层数、排名、榜单、器灵读数 | 全塔广播锁定＋器灵认证一击 |
| 协会/官方 | **白金认证阵图/徽章纹章全息** | 认证、权限、军功、称号 | 认证金光下的制式重击 |

- 外圈灯牌一律用**全息光带/数据流/金符文**，不做霓虹灯泡/夜市跑马灯；
- 白天环境用全息半透明＋发光描边，金/白金光做仪式感（R1 不启用夜景）。

## 五、与既有科技装备的承接（不重复建设）
- 灵环智能手环：全民标配的腕部 AR 投影入口，**所有技能盘/卡/徽章环默认从灵环弹出**；
- 护臂光脑：战斗中展开更大面板/卡牌栏；
- 黑金卡：付费/结算确认动作（徐芸芸加点的支付动作可走黑金卡，不出现实支付界面）；
- 空间戒指：道具/卡的"取出"可与实体化合并（取出即实体化）；
- 外骨骼/医疗舱：晶体护盾、修复进度等沿用微观/医疗 UI（血细胞/基因链、红色警告框）。

## 六、红线清单（出图/分镜自检）
1. 不出现外部商品/抽卡/抽奖/转盘/标价/库存/ALL IN 等词与图形（溯源仅在公共库文档）；
2. 五系配色不互换，统一 L 角框/等宽字体/扫描线/边缘光；
3. 不新增技能、不擅改数值与因果（暴食/进化/加点均为既有设定）；
4. 进化＝渐进成长（拔高/光柱），不做瞬时变身；
5. 战斗高光正拍不被 UI 面板长期遮挡（面板是"操作瞬间"，不是常驻马赛克）；
6. 系统 UI 与真实空间交互（投影落地面、光照环境、被物理遮挡），不空漂。
