## 加戏 A｜场 9-1：全息广告 ＋ 塔下盘口（市井垫场）

**目的**：用一镜横移把通天广场的市井气和商业噪音一次铺开，与黑塔的庄严沉默形成反差；越吵，后面一拳定场越静。属纯背景演出，不新增任何情节。

**在「旁白：战力破三百万，方可在通天塔留名，受万人敬仰。」之后，加入：**

```markdown
*一镜横移：广场两侧全息广告挨个亮起，霓虹一路淌过去——*
*全息广告：【武圣同款战甲，留名立减！】【战力不够，灵液来凑】【测不高，不要钱】*
△ 塔边一个Q版小摊，摊主老头把电子盘口拍得啪啪响。
摊主：兵王罗峰，一赔三！现场押注，落子无悔啊！
△ 他抬头看见人高马大的徐琨，愣了愣，低头在盘口末尾添了一行——
*屏内小字：【不认识的大个：一赔……待定】*
```

## 加戏 B｜场 9-1：黑塔吞光 · 小兽第一次怂

**目的**：通天塔的深不可测不靠台词解释，而靠"最能损、最能报数据"的小兽扫不出来、还往后缩来反衬——喜剧担当发怵，比旁白说一百句"神秘"都管用。

**在「△ 通天塔通体漆黑、上古纹路密布，光线到塔面即被吞掉，不反光。」之后，加入：**

```markdown
△ 小兽习惯性地抬手一扫，要给塔身估个值。
△ 它的小屏闪了两下，数字没出来，反倒"滋滋"冒了缕青烟。
AI助理（声音压得很低）：扫描……失败。这东西不在我的表里。
△ 它往徐琨肩后缩了缩，一身毛还是炸着的。
AI助理（小声）：别的我都能损两句，这塔……我有点不想看。
△ 徐琨抬头，黑塔沉默地吞着光，像什么都没听见。
```

**边界**：AI 只表现"读不懂、发怵"，**不解释塔的来历、不命名任何超凡存在**。

## 加戏 C｜场 9-7：三百万定格 · 嘴硬小兽

**目的**：金光冲天、全场死寂之间，留一个极小的喜剧落点——小兽举着打赌的小牌子被当场烧穿，嘴硬到发抖，既不破坏庄严，又让观众在屏息时漏出一声笑。

**在「*屏内特写：【3，000，000】*」之后，加入：**

```markdown
△ 小兽举着一块小牌子，上面写着"最多一百八十万，输了我吃手环"，整只兽僵在半空。
△ 金光扫过，小牌子"啪"地烧成灰。
AI助理（嘴硬，声音却在抖）：……手环是合金的，不好消化。
△ Q版：它原地转了两圈，一头扎进徐琨校服口袋，只露个尾巴尖在外头发抖。
*巨大的【3，000，000】悬在广场上空，把那截尾巴照得金光锃亮。*
```

## 加戏 D｜场 9-9：尊号砸屏 · 爱·打·篮·球

**目的**：钩子 9 本就是笑钩，把它做成伍六七式"巨大文字砸屏"——庄严仪式感有多足，这四个字就有多荒诞；顺带让篮球道具提前入画，呼应下场市民"签在我篮球上"。

**在「罗峰（内心）：新晋武圣，就这尊号？」之后，加入：**

```markdown
△ 庄严金光里，一个Q版篮球"啵"地弹了两下，不紧不慢滚过烫金大字。
*【爱·打·篮·球】四个字被无限放大、反复砸屏，最后"哐"地钉在塔顶。*
AI助理（笑到捶地）：武圣！留名！爱打篮球！哈哈哈哈——
△ 它没笑完，被塔上一道余金光"啪"地拍扁成一张小兽贴纸。
△ 贴纸晃晃悠悠飘下来，正好贴在市民递起的一只篮球上。
```

## 本单小结
- A 垫市井、B 立神秘、C 在庄严里偷一个笑点、D 把笑钩放到最大，四节合起来是"喧闹—发怵—屏息—爆笑"的伍六七式波浪。
- 四处合计约 +40 秒：A 的横移代替若干人群切镜，C/D 可压缩罗峰与市民的重复反应镜头，10 分钟结构不变。
- **情节、因果、出拳次数、尊号、钩子编号与 ED 钉子全部一字未动**；小兽在黑塔前只读不懂、只会怕，守住世界观边界。
