# 第一部分 · 世界观总纲：赛博灵气

## 1.1 世界状态（一句话）

约百年前灵气复苏，人类科技不但没有断代，反而借**灵气能源 + 异兽材料**一路点满——这不是古代修真世界，而是"霓虹灯照常亮、外卖照常点、算法照常割韭菜，只是城市天际线之外就是怪兽"的**赛博高武未来**。

## 1.2 纪年与社会基调

- 蓝星 · 华夏联邦。人类在荒野化的大陆上收缩进巨型"**环壁都市**"，荒野区是怪兽与旧时代废墟的天下。
- **江东市**：江南大区重要环壁都市，人口千万级，第一季唯一主城地图。
- 社会表层高度繁华：全息广告铺满夜空，无人车、无人机、智能助理无处不在；社会底层逻辑残酷——城市之外就是死亡，武者是凌驾一切的最高阶级。
- 喜剧基调来源：赛博生活的一切破事（网贷、杀熟、认证失败、售后扯皮）原封不动地长在高武社会里，用喜剧外壳衬"人类在怪兽嘴边过日子"的悲剧内核。

## 1.3 环壁都市三层结构（江东市固定城市设定）

| 圈层 | 固定设定 |
|---|---|
| **外环防御带（环壁）** | 高约百米的合金城墙，墙体蚀刻阵纹电路、嵌入防空激光炮阵与能量盾发生器；墙外即荒野区；墙顶是城防军巡逻道。城墙只挡地面，**空中没有永久穹顶**（仅战时拉起局部能量拦截网）。 |
| **主城** | 若干城区，摩天楼群、立体交通、全息街区、磁轨列车线；老小区与新摩天楼并存（徐家老房子的年代感由此成立）。 |
| **内环（权力核心）** | 市政大楼、武道协会总部、通天广场与**通天塔**。 |

> **关键因果（解释空袭为何成立）**：环壁只防地面兽潮，飞行异兽能越过城墙——所以赤炎魔鹫群一旦突破防空网，就能直接出现在主城街道上空。这是环壁都市唯一的正面破口，也是全城对空袭反应如此剧烈的原因。

## 1.4 灵气 × 科技融合原理（全季视觉一致性的根基）

灵气是一种**可被仪表测量的能源**（有灵气浓度、灵子指数等读数），它和科技互相喂大：

1. **能源**：灵气充电/灵子电池/充电桩；阵纹直接蚀刻在电路板上（"阵法电路"），能量盾、激光阵都靠灵子供能。
2. **材料**：异兽是工业原料——鳞甲进合金配方，兽血做针剂与营养液，妖丹是电池核心。
3. **两条路线长期并行、且杂交成主流**：
   - 传统线：丹药、御剑、拳法、符箓；
   - 科技线：针剂、飞行器、外骨骼、芯片；
   - 杂交线（社会主流）：符箓芯片、纳米法器、电磁+阵纹武器。
4. **武道可被仪器量化**：气血值、拳力、战力评级都能测。所有"系统面板"在视觉上本质都是**量化仪表的 AR 成像**——这是把"系统流"统一进赛博世界观的钥匙。

# 第二部分 · 四大基础设施体系

## 2.1 个人终端与智能体（AI）

### ① 灵环（全民智能手环，出生即绑定）
- 身份证 / 学籍 / 医保 / 支付 / 门禁 / 信用分，一环打通。
- 背侧生物传感器：心率、体温、睡眠、**基础气血读数**（民用精度；武者另有高精度设备）。
- 抬腕弹出半全息小屏，手势操作；可切换视网膜 AR 模式；支付支持碰一碰、付款码、虹膜。
- 液态金属材质，贴合皮肤、防水防电，外观颜色可自定义。

### ② 武者通讯手表（注册武者标配）
- 卫星与低空网络双链路；荒野区可用离线缓存卫星地图。
- 一键 **SOS 紧急救援信号 + 定位**，直连城防军与武道协会。
- 战斗遥测：拳力 / 速度 / 气血实时记录，电子武者证、任务接单、小队位置共享、危险等级提示。

### ③ 护臂光脑（高阶 / 军方 / 协会高层）
- 银灰护臂形态：**目标实力扫描**、符文 / 语言翻译、大容量资料库、意识接驳虚拟空间。
- 第一季作为"顶级科技长这样"的参照（军方特招场景、协会高层），不普及。

### ④ 智能体（AI）生态
- 每个人的终端都有初级 AI 助理，形象自选（小精灵 / 兽形 / 机械球），管日程、导航、搜数据、代回话。
- 社会各环节全面 AI 化：无人车、店铺机械臂、医疗 AI、城防预警 AI、**贷款推销 AI**（徐芸芸手机里的"手机爹"）。
- **通天塔器灵**：上古文明遗留的真正智能，管理万层试炼、认证、留名、全塔广播——第一季科技天花板。
- **智能体边界（防穿保因果）**：普通 AI 读不懂武道意境、扫 SSS 级目标只会数据溢出错乱，只能报能量量级；"查无此人 / 匹配失败 / 查无信息"因此全部成立。

## 2.2 灵网与虚拟空间

- **灵网**：联邦全域网络，手机 / 手环 / 全息屏全接入。
- **武道网 APP**：身份认证、特权清单、津贴到账、任务征召；一级战备时征召令可一键推送到所有注册武者终端。
- **虚拟对战室**：意识感应头盔登录，全息模拟异兽与对手。学校与武馆是基础款，通天塔内是顶级款。
- **全城全息层**：巨型空中光幕（广告 / 新闻 / 警报）、楼宇立面全息影像、街道上空悬浮的 AR 信息层（可关闭）。
- **算法社会（讽刺与喜剧素材）**：信用分、大数据杀熟、向高中生精准推送"武道贷"——为徐芸芸网贷提供完整因果温床。

## 2.3 都市风貌与交通

- **天际线**：数百米至千米摩天楼群，楼体全息广告如河水流动；空中轻轨穿梭楼宇之间；夜雾、霓虹、雨水反光构成赛博底色。
- **地面**：无人出租车与巴士（方向盘可收起）、电助力共享单车站、机械臂摊贩、自动贩卖机矩阵、无人配送机航线、人脸识别闸机、巡逻无人机、电子站牌、分拣机器人。
- **立体交通分层**：物流层 / 车行层 / 空中管制层（私人飞行器受限，空中以军方、急救、物流为主）。
- **城际**：磁悬浮高铁（叶清漪往返帝都 / 江东的载体）。
- **防空设施（空袭专用固定道具）**：警报塔、街区广播、应急避难引导光带、楼顶激光防空炮阵列、拦截导弹巢。
- **能源质感**：灵子电站、充电桩林立；旧电线、老招牌与全息屏并存，制造年代层叠的质感。
