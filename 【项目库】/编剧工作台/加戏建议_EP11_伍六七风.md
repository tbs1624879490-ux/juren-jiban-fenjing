## 加戏 A｜护妹出拳段（场 11-3）：宣告式护短金句 ＋ 纯色底定镜

**目的**：本集唯一一句高光金句（"我今天就要___，我看谁敢___"句式，全集只用这一次）。用纯色暗金底定镜把时间按停，金句一句砸下、一拳轰出，对齐伍六七"我今天就要带她走，我看谁敢拦我"的纯正剧演法——不掺一个笑点，保证高燃稀缺。

**将 11-3「徐琨（眼神冰到极点）：敢动我妹——」替换/扩写为：**

```markdown
△ 没有人看清他是怎么转身的。
△ 世界骤然失声，百倍重力下粘稠的空气，仿佛被一只手按停。
△ 纯色暗金底定镜——画面里只剩徐琨半张侧脸，眼瞳冷得没有一丝温度。
徐琨（一字一字）：我今天就要护她周全，走出这座塔。
徐琨（声音陡然压低）：我看谁敢——动我妹一根头发。
△ 他脚下石面无声裂开蛛网纹，拳，却还停在腰间。
△ 一只暗金大拳，带着撕裂空气的爆鸣，后发先至，迎着秦天轰出。
▶钩子3【爽点】他转身，一拳轰出。
△ 拳锋，精准地撞上秦天胸口。
```

**边界**：秦天仍是被这一拳透胸、撞穿塔壁、坠塔而死（11-4 起一字不动）；金句只换台词写法，不改出拳时机与结果。

## 加戏 B｜妹妹擦伤段（场 11-9）：AI 小兽战后冷面吐槽

**目的**：高燃之后给一个极短缓冲。用鸡大保式"数据吓断片"的怂萌吐槽泄压，同时让徐琨"把妹妹往身后带"的小动作收住情绪，再无缝接入他直面宋婉词，不稀释兄妹情感。

**在 11-9「▶钩子9【情感】妹妹脖上，一道血痕。」之后、「△ 他起身，转身，坦然迎上宋婉词的目光。」之前，加入：**

```markdown
△ 徐芸芸脖颈上，一道细细血痕，微微泛红。
罗峰（检查后，松气）：只是擦伤，没伤到要害。
△ 徐琨悬着的心，这才落地。
徐琨（轻抚妹妹头顶，声音低沉）：谁让你，靠那么近。
▶钩子9【情感】妹妹脖上，一道血痕。
△ 腕上灵环微光一闪，小兽探出头，飞快瞥了眼塔壁破洞，"唰"地缩了缩脖子。
AI助理（小声汇报）：报告……附近敌意指数，归零。
AI助理（更小声）：宿主，下回出拳能不能提前吱一声？我后台数据，全吓断片了。
△ 徐琨没理它，只把妹妹往自己身后轻轻带了半步。
△ 他起身，转身，坦然迎上宋婉词的目光。
```

**边界**：AI 只报"敌意归零"这一现象与情绪，不解释拳力、不命名血脉（守住"读不懂超凡"）。
【　采纳 / 修改 / 弃用　】

## 加戏 C｜认出秦天段（场 11-6）：王建国 Q 版颜艺 ＋ 小字砸屏

**目的**：把教育局长"摊上大事"的恐慌做成伍六七式配角颜艺（灵魂出窍＋【完了】小字），观众在这里笑一下，正好缓冲坠尸的沉重；笑点只落在官僚身上，不碰死者、不碰徐琨的高燃。

**在 11-6「△ 王建国腿一软，差点从主席台上滑下去。」之后、「王建国（内心）：秦家的孩子，死在我的考场上……完了！」之前，加入：**

```markdown
市民（看清，倒吸凉气）：是……秦天？帝都秦家的那个少爷？！
△ 王建国腿一软，差点从主席台上滑下去。
△ Q版：他眼前一黑，半透明的小人魂儿从嘴里飘出半截，打着旋儿。
△ 一个黑体小字"啪"地砸在他头顶——【完了】，字还颤了三颤。
△ 秘书手忙脚乱把他按回座位，他嘴唇直哆嗦，一个整字都蹦不出来。
王建国（内心）：秦家的孩子，死在我的考场上……完了！
```

## 加戏 D（可选·克制）｜ED 段（场 11-11）：AI 小兽望梯炸毛

**目的**：无台词的 5 秒小动作。让小兽望一眼通往第一万层的台阶就炸毛、调暗投影缩回手环——用吉祥物的"怂"替观众把悬起来，为 EP12 白虹贯顶的刺客杀局预热；不碰 ED 钉子与下集预告。

**在 11-11「徐琨：高考，还没考完。」之后、「△ 宋婉词站在一旁，看着他的背影，没有阻拦。」之前，加入：**

```markdown
△ 徐芸芸后怕未消，紧紧攥住哥哥的衣角。
徐芸芸（小声）：哥……
△ 徐琨低头，看着妹妹，又望向通往第一万层的最后台阶。
徐琨（沉声）：没事了。
徐琨：高考，还没考完。
△ 灵环微光闪动，小兽顺着他的目光望向那道台阶，浑身绒毛"唰"地炸起。
△ 它一声不吭缩回手环，只露出半只眼睛，默默把投影亮度调到了最暗。
△ 宋婉词站在一旁，看着他的背影，没有阻拦。
```

## 本单小结

- A 为**主推且唯一高光**（金句＋纯色底，约 +13 秒）；B、C 为高燃前后缓冲（约 +10 / +8 秒）；D 为可选预热（约 +6 秒），四条合计约 **+37 秒**。
- 时长消化：A 的定镜可由 11-4/11-5 秦天倒飞与坠塔的慢镜、广场反应空镜各压缩 2–3 秒抵充；B、C、D 从 11-7 查监控、11-11 ED 停留的既定空镜里匀，整体不超 10 分钟结构。
- **情节因果零改动**：秦天仍为偷袭徐芸芸、被徐琨一拳透胸后坠塔而死，死法与结果不变；监控失灵、宋婉词定性、ED 钉子与全部钩子编号原样保留；AI 全程只报现象，读不出超凡。
