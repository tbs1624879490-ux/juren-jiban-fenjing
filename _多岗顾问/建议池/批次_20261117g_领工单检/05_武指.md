# 05武指检·连跑领工单v2（批次g·20261117）

受检件：`0、分场分幕和剧本/连跑领工单_四会话并行_20261117.md`（v2·检）
依据：`_多岗顾问/岗位卡/05_武指.md`＋`_多岗顾问/岗位卡/00_总底盘.md`§文戏打戏判定

## ①检结论

**主干过，三处缺口。**

1. §四执行锚武指维三条主锚——「威压显形＝文戏·无法判定默认文戏·文戏一镜一动作／打戏按发力链拆拍」——**均在**，主干合格。
2. 但**SOP-0开场三读不含总底盘与岗位卡**（B/C/D只读领工单＋分场方案＋标杆件），文武判定口径全季只在§四这一处可见；而§四缺**打戏正向判定**（肢体接触/能量对轰/物理冲击都算打，撞门框/掀翻/坠塔也算，杂兵清场远景也算）与**「蓄力未命中／血脉显形／面板弹出＝文戏」**——B/C/D新会话遇这类场会拿不准，而总底盘明令「拿不准默认文戏」兜不住正向判定缺失（判成文戏还是打戏直接决定一镜一动作还是拆拍）。
3. **SOP-1切拍纯行数驱动（9行/拍），零打戏条款**：打戏按发力链拆拍与9行/拍估拍**冲突时谁优先没写**；且SOP-1第3步拍界落点四项（集尾钩/喜眼段收/场景切换/台词群收口）**全是文戏收口**——按这个切，一招五段（起手→出招→过程→命中→收势）会被拦腰切断，发力链断链＝打击感散架。
4. 文武标记列：**要入，但不入SOP-2十节**——十节是regex硬校验的标杆件骨架，加列＝改格式＝全库返工；落点应在SOP-1拍账（切拍时每拍标〔文/武〕二字，零成本，后续出词和十岗检都直接受益）。

## ②补条目清单（挂SOP节号）

1. **§四执行锚补两句**（挂：§四·无SOP节号）：打戏正向判定「打戏＝肢体接触/能量对轰/物理冲击（撞门框/掀翻/坠塔都算·杂兵清场远景也算打）」＋文戏补锚「蓄力未命中／血脉显形／面板弹出＝文戏」。理由：B/C/D三读够不着总底盘，§四是唯一口径入口。
2. **SOP-1第2步补一句冲突优先级**（挂：SOP-1·2）：打戏场**发力链拆拍优先**——9行/拍估拍只作文戏参考与打戏下限，发力链要几拍拆几拍，宁多勿断；SOP-1既有「不压缩以实际为准·王导勾」已半覆盖，只需把「实际」锚死为「打戏＝发力链拍数／文戏＝行数估拍」，改动一行。
3. **SOP-1第3步补打戏拍界**（挂：SOP-1·3）：打戏拍界压**收势/余韵拍**（打击感五拍：预备→接触→反馈→余韵→呼吸，界切在余韵与呼吸之间），禁把一招五段拦腰切断；命中拍与冲击帧不得跨拍拆散。
4. **SOP-1第4步拍账标〔文/武〕**（挂：SOP-1·4）：每拍起止行号旁标〔文/武〕二字——此即「文武标记列」的入SOP落点；不加列进SOP-2十节（regex硬校验骨架不动），标杆件零改动。
5. 无——其余武指维条款（碰撞铁律/冲击帧词族/位移写死/伤情代价/隔级链写词细则）属写词层，归岗位卡＋每批任务书管，不入领工单（领工单只管分工与切拍，照「改动最小化」不加）。
