## 乙、进口分类（接活第一步，先判类再动）

| 类别 | 判据 | 走哪条线 |
|---|---|---|
| **体检** | 已落稿（方案/切分表/单元/台账），要按岗挑刺 | 任务书（含【硬钉】＋【设计意图白名单】）→ 十岗并行子代理 → 只进建议池 |
| **选目／开段** | 开幕或开十单元段，要定戏种＋维度订单 | 影子口径：并行勾 G0–G2 → 王导勾 → 蒸订单为写镜卡 → 标杆试镜 → 冻结卡包 |
| **新写** | 剧本段拆新单元（卡包已冻结或无武戏） | 收料 → 主控按卡包落稿 |
| **改稿** | 现行稿要改，王导给了逐字口令 | 收料附现行稿 → 体检批 → 只出建议不落稿 |
| **三版本** | 同单元要 3 套表现手法 | 任务书锁「拍什么不变，只变怎么拍」 |
| **出片** | 王导说贴卡／出片 | 先问登记阀 → 出片前清单 → 逐镜卡 → 同会话登台账 |

**收料纪律**：王导原话一字不改落 `收料/`（带日期）；口述也落盘；禁摘要、禁凭记忆。

## 丙、七步链（一步不跳，逐步有产物）

1. **收料落盘** → `收料/<带日期>.txt`。
2. **写任务书**：大白话，落 `任务书/`；【硬钉】逐条列王导本轮口令；【设计意图白名单】列明哪些是拍板设计、禁报为缺陷（体检批必给）。**输出纪律**：各岗只交结论＋一句为什么，禁思考过程、禁整段成稿词、禁编造文件名。
3. **发射（路径A）**：主控按任务书 roles 并行起十岗子代理（一条消息多 Agent 调用，互不见面）；每岗先真读自己的岗位卡与总底盘，再读任务书与体检对象。
4. **收齐**：以各岗返回报告为准；缺岗即补发，失败不得与成功同形。
5. **合流**：主控确定性合流（无模型裁决）→ `建议池/批次_*/` 落每岗建议原文＋`合并摘要.md`＋`待拍板清单`。**多岗只建议不落稿**，终选权与执笔权永远在王导／主控。
6. **王导逐勾 → 回写 → 升卡**：待拍板清单逐条勾 ✔/✘（带原因）；通用新钉经王导拍板后写入 `岗位卡/00_总底盘.md` 升卡台账（只增不删）。
7. **落稿与交付**：主控执笔；交付前过三关——对账零静默丢失＋机检三脚本＋技法来源清单。回复只给文件链接＋合并摘要＋待拍板清单。
