# 巨则 V1.0 · 03 创作铁则

> 分镜格式与通用铁则。所有分镜单元必须遵守；校验脚本以此判 ERROR。

---

## 一、分镜文件格式

### 头部（每个单元开篇）
- **标题**：第 X 季·单元 N《单元名》
- **画质**：如 8K / 3D 动漫 CG 质感
- **全局铁律**：本单元贯穿的可见 / 可听硬约束（正向表达）
- **模型权重 / 模型版本**
- **色调标准**
- **场景环境**：材质、光源方向、地面 / 墙面反射、外景动态，逐细节写全
- **人物固定站位**：谁在前后左右、朝向、距离、关键道具在谁手上

### 每分镜六要素
1. **景别**（7 档，见下）
2. **拍摄角度**
3. **主体动态**
4. **台词 / OS**
5. **环境音**
6. **光影细节**

### 转场
- 硬切默认直接切、不单独写转场行；只有设计过的非硬切转场（如前景遮罩）才占一行，且单元 N 末尾转场必须指向 N+1。

## 二、景别 7 档与隔级跳

- 档位（远→近）：0 大远景｜1 远景｜2 全景｜3 中景｜4 近景（胸上 / 中近景）｜5 特写（眼 / 手 / 微距）｜6 大特写。
- **相邻硬切镜头档位差必须 ≥2**，同档 / 相邻档硬切判 ERROR（分镜间、分镜内硬切处、跨单元首尾三处都查）。
- 连续推 / 拉 / 摇 / 移 / 环绕造成的景别渐变不算硬切；跨主体快切组豁免。
- 什么景别框什么内容：近景只写胸上，框不下腿脚 / 全身位移。

## 三、通用铁则（正向表达）

1. **直写角色名**：除台词 / OS 引号行外，所有描述文字直写角色名，不使用你 / 我 / 他 / 她。
2. **场景自包含**：单看任一单元，场景 / 人物 / 光源完整成立；同一地点重复出现，把上一单元【场景环境】一字不差复制，不写"参照 / 同上 / 承接"。
3. **时段唯一**：一个单元只占一个时段，正面写当时天光与光源方向。
4. **有卡挂钩**：有参考卡的人物 / 异种，分镜只写动作 / 微表情 / 光效 / 镜头，不写穿着与外观本体；无卡路人才描述外观。
5. **台词开口、不打字幕**：角色台词以口型 + 声音呈现，不打对白字幕；技能名可走屏内书法字卡。
6. **演法克制**：情绪到嘴角微翘 / 眼底变化为止，不咧嘴、不尬笑、不眉飞色舞；动作喜剧（炸毛、疼叫、干饭）保留。
7. **道具锁形**：道具首次定形（数量 / 颜色 / 材质 / 标签）后，在场单元逐镜锁齐，不缩水、不变色、不飞回。
8. **POV 语法**：主观视角不出现本人正脸，只露手 / 肢体局部 / 道具；要演本人反应切客观镜。
9. **正名统一**：徐琨、叶清漪、徐芸芸、糖糖、宋婉词、林万钧、雷沧等专名不写错。
10. **成年设定**：主角团为刚高考完的成年学生；仅糖糖等被救孩童可写低龄。

## 四、本书专属视觉铁则

- **体型参照镜头**：每个成长阶段安排与门框 / 课桌 / 楼 / 城 / 星球的对比镜头，直观交代身高。
- **干饭喜剧**：进食镜头用空盘叠塔、食材对比、旁人反应特写，节奏快、给反应。
- **大战后泄压阀**：严肃爆杀后接一个干饭 / 市井笑点（打饱嗝、问孜然）。
- **巨人色彩签名**：暗金气血 / 惨绿"饿"字 / 叶清漪冰蓝 / 黑日残黑（详见美术库）。
- **"锚"的文戏**：母亲（饿不饿 / 瘦了 / 疼不疼）、叶清漪（并肩点化）、英灵碑，停顿留白，不演成纯搞笑。
