## 一、项目是什么

灵气复苏高武世界，武考落榜的穿越者**徐琨**暴食激活 **SSS 级巨人血脉**，以"吃→睡→长高→力量指数级暴涨→打脸"为核心循环，从 165cm 废柴成长为万米巨神，最终"大小如意"归元回家。

- 卖点：体型无限膨胀的视觉奇观 + 干饭喜剧 + 一拳爆星的爽感。
- 题眼：越强越孤独，靠家人 / 爱人 / 战友这几根"锚"始终记得自己是徐琨、回得了家。

## 三、标准创作工作流（不可跳步）

1. **改编方案先行（强制门禁）**：先有 `编剧工作台/_改编总方案.md`，再逐段出《分段编剧意见单》，**经王导确认后才开写该段分镜**。
2. **触发词调取**：写每个单元前，先读总索引，按关键词命中并 Read 对应库（场景 / 角色 / 技能 / 美术 / 故事线 / 喜剧梗）。
3. **出分镜**：按 03 创作铁则的"头部六栏 + 每镜六要素"格式逐镜写。
4. **一致性校验**：每幕完成跑 `check_consistency.py`，做到 ERROR=0 才交付。
5. **回写闭环**：落地与意见单有偏差，回注意见单；精彩新段落回写对应库。
6. **更新前先备份**：改任何库前先跑 `backup.sh`。
