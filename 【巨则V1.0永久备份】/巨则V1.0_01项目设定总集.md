## 一、作品信息

- 体量：437 章 / 约 121.7 万字｜类型：灵气复苏 · 高武 · 巨人流爽文
- 主角开局年龄：徐琨 19 岁（穿越 18 年），刚高考完，**成年**。

## 二、金手指：巨人血脉（暴食 + 进化）

- **暴食**：进食获取能量；食材能级越高（异兽→皇者→武帝→星辰），能量越大。
- **进化**：体型每增一分，力量 / 防御 / 耐力 / 气血 / 敏捷指数级提升，骨密度与体重同步暴涨。
- **气海异象**：气海中央悬浮惨绿色 **"饿"字**，可鲸吞天地精气。
- **成长副作用**：体型过大即"人形灾厄"，普通动作引发地质气象灾害、无法近城、无法与常人相处——归元的根本动因。
- **终极**：无限生长触顶后需自我归一，成就 **大小如意（大如星辰、小如凡人）**。
- **短板**：纯陆地霸主，不擅飞行法则，靠弹跳 / 御风 / 后期月面飞行。

## 四、世界版图（随成长逐级扩张）

- **蓝星**：灵气复苏，荒野分低 / 中 / 高危 / 禁区；异兽成潮，异族经空间裂隙"刷新"异兽；一级战备注册武者须无条件应召。
- **大荒**（蓝星外超级位面，面积千百倍）：南荒边缘万鳞城（应帝领地，不足大荒百分之一）；四方禁区（极北不死冰原 / 西荒万虫巢 / 南荒蛮神古庙 / 地下深渊）；极东巨人国度·盘神谷；扶桑神岛·太阳海（金乌）；北冥黑色死海（鲲）。
- **月域（天上明月）**：八隐世武帝本源所化八相月城；月民三族（银蟾 / 桂灵 / 望舒羽）被奴役，后解放为"月都"。
- **星空**：月都星门→星环带→星环城（第一座星空城市）；更深处有吞星兽、噬星虫与"更大的黑暗"（黑日残骸）。
