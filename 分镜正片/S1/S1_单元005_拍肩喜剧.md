【单元 005｜拍肩喜剧】
3D动漫CG写实物理，赛博灵气近未来校园8K超高清细节，电影级光影

【全局铁律】接上单元末镜李老师僵住；五密终版集1-1续；本单元五句台词按剧本原文逐字（咬牙宽慰／疼哭谢关照／霸气要求等）；拍肩的力道一次比一次重为喜剧拍眼；徐琨零外观描述；李老师零外观描述；零能力零特效
【模型权重】画质1.4，光影3.8，运镜3.4，特效2.6，动作3.8，情绪表演4.6
【音乐节拍】拍肩一声比一声重当鼓点打，疼哭的谢词混着抽气，霸气要求落地配一声诙谐扬音，脚步加快的逃走路板收口；各镜节拍秒数已入制作备注节拍映射

【色调标准】六月白日：天光白金基调，拍肩的动势吃顶光；李老师热心过头的神态吃柔光；徐琨疼出的眼泪在阳光下发亮；师生一暖一懵同框

【场景环境】江东一中操场·日。骄阳下水泥台阶与塑胶跑道交界处，金属打印机机身反光一线，跑道面映着天光的亮带；全息横幅蓝白光带在远处流转；地面映着两人影子；远景外环环壁横在天际线，街面云影缓移

【人物固定站位】李老师：徐琨身侧正面，拍肩、理衣领；徐琨：受拍位置、末镜快步逃离方向；考生群：远处队列

分镜1
景别：近景（定机位）
拍摄角度：定机位近景李老师——咬牙切齿的宽慰撑满画面
主体动态：李老师收起僵住的手势，改成咬牙切齿的宽慰，每说一句就重重拍一下徐琨的肩膀；拍肩的力道一记重过一记；徐琨的身体随每拍一晃
台词 / OS：李老师（咬牙切齿的宽慰）：「一次没考好，也不是世界末日。大不了复读一年，去私立武校再战。」
环境音：拍肩的闷响一记重过一记，宽慰的话混着咬牙的气音，操场白噪垫底
光影细节：顶光把拍肩的手臂照出发力亮边，李老师咬牙的神态吃柔光；徐琨肩部衣料随拍起皱

分镜2
景别：大特写（急推，定镜）
拍摄角度：定镜大特写徐琨的脸——疼出来的眼泪撑满画面
主体动态：徐琨疼得眼泪都出来了，眉毛拧成八字、嘴角向下撇；看着李老师咬牙切齿的表情整个人有点懵；眼泪在眼眶里晃着没落
台词 / OS：徐琨OS（疼得皱脸，一脸懵）：「不是！刚刚不还好好的吗？这关心来得，我有点承受不住啊！」
环境音：一声疼出来的抽气，眼泪打转的静拍，拍肩闷响在背景继续
光影细节：顶光把眼泪照出透亮的点，皱脸的表情肌肉走向分明；面部明暗对切

分镜3
景别：中景（定机位）
拍摄角度：定机位中景两人——断句的道谢撑满画面
主体动态：徐琨强忍疼痛、泪流满面地断句道谢，每个字都被下一记拍肩打得一颤；李老师看着这份「感动」满意地点头；两人的影子一高一矮
台词 / OS：徐琨（强忍疼痛，泪流满面）：「老师……谢谢……您……这两年……的关照。我一定……加油！」
环境音：断句的道谢混着抽气与拍肩闷响，李老师满意的鼻音一声，操场白噪退底
光影细节：白日天光把泪痕照出反光的亮线，拍肩处衣料褶皱堆起；满意点头的姿态吃柔光

分镜4
景别：特写（定机位）
拍摄角度：定镜特写李老师的手——理衣领与霸气要求收在同一框
主体动态：李老师替徐琨理了理歪掉的衣领，手法利落得像阅兵检查；放慢的语气里带着不容商量的霸气；理完在肩章位置又拍了一记收尾
台词 / OS：李老师（放缓）：「去吧。别的不求——继续加油，明年，给我考个状元回来。」
环境音：理衣领的布料窸窣，收尾一记拍肩闷响，霸气要求的尾音上扬
光影细节：白光把理领的手指照出利落亮边，衣领翻折处吃光分明；徐琨的肩膀在画缘一缩

分镜5
景别：全景（跟拍）
拍摄角度：镜头跟随逃离的脚步横移——揉肩擦泪与加快的脚步收进一框
主体动态：徐琨背对着李老师用力揉肩膀、擦了一下眼泪，听到那句霸气要求嘴角一抽、脚步瞬间加快、头都不敢回；李老师立在原地满意地目送；操场把这场误会送走
台词 / OS：徐琨OS（欲哭无泪）：「这话我敢接吗！我！」
环境音：脚步声加速的哒哒两拍，揉肩的衣料摩擦声，身后一声满意的叹
光影细节：白日天光把逃离的背影照出仓皇的亮边，影子在地面拉长狂奔；李老师的立影吃柔光
