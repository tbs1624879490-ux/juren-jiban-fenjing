## 一、项目定位

灵气复苏高武世界，武考落榜的穿越者**徐琨**暴食激活 **SSS 巨人血脉**，以 "吃→睡→长高→力量指数级暴涨→打脸" 循环，从 165cm 成长为万米巨神，最终大小如意、归元回家。



* 卖点：体型无限膨胀的视觉奇观 + 干饭喜剧 + 一拳爆星爽感。

* 题眼："你因还记得回家才是徐琨。"
