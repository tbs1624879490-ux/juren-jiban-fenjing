# 文戏库

> 按场景类型记录正反打、情绪递进、微表情；喜剧见《喜剧梗名场面库》。

## 分类骨架（随创作填充）

| 类型 | 适用 | 要点（待补） |
|---|---|---|
| 双人对话 | 徐 / 叶、家人 | 景别隔级、反应镜 |
| 多人 / 会议 | 军部、朝堂、议会 | 群像调度、权力站位 |
| 独白 | 内心、决断 | 视觉化、不堆旁白 |
| 审讯 / 谈判 | 战俘、政皇 | 张力、节奏 |
| 校园 / 日常 | 第一季 | 轻松、青春 |
| 喜剧 | 干饭、体型差 | 见喜剧梗库 |

## 演法尺度
- 克制：情绪到嘴角微翘 / 眼底变化，不咧嘴尬演。
- 非台词行直写角色名；台词开口不打字幕。
